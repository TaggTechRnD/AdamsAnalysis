Random Forest

Statistical method reference guide

Overview and appropriate use

Purpose

Random forests aggregate many randomized decision trees to make flexible predictions and measure predictive importance.

Example research questions

Can combined clinical measurements predict hospital readmission more accurately than a single tree?

Design requirements

Labeled outcome, informative predictors, sufficient training data, and appropriate validation; clustered data require grouped splitting.

Strengths

Models interactions and nonlinearities with limited manual specification.

Limitations

Harder to interpret than a single tree; apparent feature importance can be biased or misleading.

When not to use it

Do not use random-forest variable importance as proof of causal influence or evaluate on leaked training records.

Illustrative research scenario (hypothetical)

Predict one-year hospital admission from demographic and clinical indicators.

Mathematical foundation

Mathematical foundation

ensemble predictor

\(\hat{f}_{RF}(x)=\frac{1}{B}\sum_{b=1}^{B}\hat{f}_b(x)\)
View LaTeX source
\hat{f}_{RF}(x)=\frac{1}{B}\sum_{b=1}^{B}\hat{f}_b(x)

Symbols

B: number of trees; f-b(x): prediction from tree b.

Explanation

Regression random forests average predictions from trees grown on resampled data with feature randomness.

Important scope limitation

Classification forests aggregate class votes or probabilities; this equation is for regression output.

Assumptions and diagnostics

Assumptions and conditions

Features and labels are valid; training/testing split protects against leakage and correlated record duplication; predictive context is sufficiently similar to deployment.

Diagnostics to perform

Use out-of-bag and independent test results appropriately, compare training and validation metrics, check imbalance, leakage, calibration and subgroup performance.

Consequences of violations

Correlated data across splits or leakage exaggerates performance; class imbalance can conceal poor sensitivity.

Diagnostic caveats

Out-of-bag error is not a substitute for external validation when groups or time periods differ.

Understanding the results

Primary outputs

Ensemble predictions, out-of-bag or validation error, and optional variable-importance measures.

Inference and tests

Classical coefficient p-values are not intrinsic; uncertainty can be studied with suitable resampling methods.

Effect sizes and intervals

Compare calibrated predictions and meaningful outcome contrasts, with bootstrap or other suitable prediction intervals where justified.

Model fit and performance

Use out-of-bag or separate-test performance; report AUC/calibration for classification or RMSE/MAE for regression.

Interpreting results

Lower held-out prediction error indicates better generalization to similar unseen data under the validation design.

Common mistakes

Variable importance does not prove causality; out-of-bag evaluation may be insufficient under temporal or clustered dependence.

Example report wording (placeholder values)

Random forest held-out [metric] = [value] ([resampling design]); predictors = [count].

R tutorial

Learning goal

Classify outcomes with an ensemble of trees.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

randomForest

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

fit<-randomForest::randomForest(y~x1+x2+x3,data=train,ntree=200)
p<-predict(fit,newdata=test)
print(table(truth=test$y,predicted=p))

Output to inspect

Holdout confusion matrix and class-level performance.

Limitations and checks

Feature importance is not causal; tune parameters with cross-validation.

Python tutorial

Learning goal

Classify outcomes with an ensemble of trees.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import confusion_matrix
fit=RandomForestClassifier(n_estimators=200,random_state=2026).fit(train[["x1","x2","x3"]],train.y)
p=fit.predict(test[["x1","x2","x3"]])
print(confusion_matrix(test.y,p))
