Cox Proportional Hazards Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Cox proportional hazards regression estimates covariate associations with the instantaneous event rate over follow-up without specifying a baseline hazard form.

Example research questions

Are baseline risk factors associated with time until first cardiovascular event?

Design requirements

Event or censoring time, event indicator, relevant predictors, and proportional-hazards assumptions for standard interpretation.

Strengths

Handles right-censored survival data and produces hazard ratios while adjusting for covariates.

Limitations

Hazard ratios are not risk ratios; nonproportional hazards and informative censoring complicate inference.

When not to use it

Do not substitute ordinary logistic regression when follow-up durations differ materially and timing matters.

Illustrative research scenario (hypothetical)

Estimate age-adjusted hazard ratios for incident stroke across smoking categories.

Mathematical foundation

Mathematical foundation

survival model

h(t\mid\boldsymbol{x})=h_0(t)\exp(\boldsymbol{x}^\top\boldsymbol{\beta})

Symbols

h: hazard rate; h0: baseline hazard; exp(β): hazard ratios for covariate changes.

Explanation

Models relative instantaneous event hazards without specifying the baseline hazard form.

Important scope limitation

Proportional hazards and noninformative censoring assumptions need evaluation.

Assumptions and diagnostics

Assumptions and conditions

Event times and censoring status are correctly recorded with valid time origin; standard Cox model assumes proportional hazards and conditionally noninformative censoring.

Diagnostics to perform

Plot Schoenfeld residuals against time, inspect log-minus-log curves when helpful, assess functional form via residuals, and review censoring patterns and time origin.

Consequences of violations

Nonproportional hazards makes a single hazard ratio time dependent; informative censoring and incorrect time origin bias hazard estimates.

Diagnostic caveats

A nonsignificant proportional-hazards test does not prove proportionality; censoring ignorability is not testable from observed outcomes alone.

Understanding the results

Primary outputs

Log-hazard coefficients, hazard ratios (HRs), standard errors and adjusted survival predictions.

Inference and tests

Wald, score or LR tests and confidence intervals describe relative hazards under proportional-hazards and censoring assumptions.

Effect sizes and intervals

HR with CI is a relative instantaneous hazard contrast, not a risk ratio or absolute survival difference.

Model fit and performance

Schoenfeld residuals address proportional-hazards; concordance and calibration assess predictive aspects; likelihood metrics compare fits.

Interpreting results

HR = 1.4 indicates an estimated 40% greater instantaneous hazard at a given time conditional on the model.

Common mistakes

HR 1.4 does not mean 40% more people experience the event or a 40% shorter survival time.

Example report wording (placeholder values)

Adjusted HR([X]) = [HR] (95% CI [limits]; p = [p]); proportional-hazards assessment = [result].

R tutorial

Learning goal

Model covariate effects on the hazard of an event.

Simulated data

Time-to-event outcomes with random right censoring and treatment/risk covariates.

Packages

survival

R example

set.seed(2026)
n <- 250
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
rate <- 0.08*exp(0.5*x - 0.5*treatment)
true_time <- rexp(n, rate=rate)
censor_time <- runif(n, 5, 22)
time <- pmin(true_time, censor_time)
event <- as.integer(true_time <= censor_time)
d <- data.frame(time, event, x, treatment)

fit<-survival::coxph(survival::Surv(time,event)~x+treatment,data=d)
print(summary(fit))

Output to inspect

Hazard ratios and CIs; check proportional hazards.

Limitations and checks

A hazard ratio is not a risk ratio or a difference in mean survival time.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 250
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
rate = .08*np.exp(.5*x - .5*treatment)
true_time = rng.exponential(scale=1/rate)
censor_time = rng.uniform(5,22,n)
time = np.minimum(true_time,censor_time)
event = (true_time <= censor_time).astype(int)
d = pd.DataFrame({"time":time,"event":event,"x":x,"treatment":treatment})

# Install optional dependency beforehand: pip install lifelines
from lifelines import CoxPHFitter
fit=CoxPHFitter().fit(d,duration_col="time",event_col="event")
print(fit.summary[["coef","exp(coef)","p"]])
