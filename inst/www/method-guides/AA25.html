Generalized Linear Mixed Model (GLMM)

Statistical method reference guide

Overview and appropriate use

Purpose

Generalized linear mixed models extend generalized regression to clustered or repeated outcomes such as binary responses and event counts.

Example research questions

Do patients' odds of hospital readmission differ by treatment while accounting for hospital clustering?

Design requirements

A suitable outcome distribution and link, meaningful clustering units, and adequate data to estimate random effects.

Strengths

Models non-Gaussian outcomes while accounting for dependence within groups.

Limitations

Complex likelihood estimation, convergence difficulties, and interpretation of conditional effects require care.

When not to use it

Do not apply a Gaussian mixed model to binary events merely because observations are repeated.

Illustrative research scenario (hypothetical)

Analyze repeated yes-or-no medication-adherence reports with patient random intercepts.

Mathematical foundation

Mathematical foundation

generalized mixed model

\(g\!\left(E[Y_i\mid\boldsymbol{b}]\right)=\boldsymbol{x}_i^\top\boldsymbol{\beta}+\boldsymbol{z}_i^\top\boldsymbol{b}\)
View LaTeX source
g\!\left(E[Y_i\mid\boldsymbol{b}]\right)=\boldsymbol{x}_i^\top\boldsymbol{\beta}+\boldsymbol{z}_i^\top\boldsymbol{b}

Symbols

g: link function; β: fixed coefficients; b: random effects; Y: possibly non-Gaussian outcome.

Explanation

Extends regression for non-Gaussian outcomes to repeated and clustered measurements.

Important scope limitation

Interpretation is usually conditional on random effects; suitable distributions and link functions depend on outcome type.

Assumptions and diagnostics

Assumptions and conditions

Outcome family and link match the data; observations are correctly clustered with identifiable random effects and a plausible conditional mean/correlation structure.

Diagnostics to perform

Inspect dispersion and zero patterns for count families, calibrated probabilities for binary families, simulation-based residuals, convergence and singularity flags, and cluster counts.

Consequences of violations

Wrong family or link, sparse clusters or poorly identified random effects can bias coefficients or misstate uncertainty.

Diagnostic caveats

A converged fit does not guarantee valid model specification. Diagnostic expectations vary substantially across GLMM families.

Understanding the results

Primary outputs

Fixed-effect estimates on link scale, conditional predictions, random-effect variances and distribution family.

Inference and tests

Wald/LR tests and intervals depend on family and approximation; report inferential method.

Effect sizes and intervals

Exponentiated coefficients may be conditional ORs or IRRs for common logit/log-link families; include intervals.

Model fit and performance

Conditional/marginal predictions, residual checks and AIC for comparable likelihood fits; no universal R².

Interpreting results

In a logit GLMM an OR describes a conditional odds contrast given random effects, not a population-average contrast.

Common mistakes

Do not mix conditional GLMM effects with GEE population-average effects or interpret a GLMM OR as a risk ratio.

Example report wording (placeholder values)

Conditional [OR/IRR] for [X] = [effect] (95% CI [lower], [upper]); random-effect variance = [var].

R tutorial

Learning goal

Model binary outcomes clustered within participants.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

lme4

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

set.seed(2026)
d$id<-rep(seq_len(70),each=4)
d$subject<-rnorm(70)[d$id]
d$y<-rbinom(nrow(d),1,plogis(-.5+.8*d$x+.6*d$subject))
fit<-lme4::glmer(y~x+(1|id),data=d,family=binomial())
print(summary(fit))

Output to inspect

Conditional fixed effects and between-person heterogeneity.

Limitations and checks

Python uses a Bayesian variational fit; numerical estimates and uncertainty differ from frequentist lme4.

Python tutorial

Learning goal

Model binary outcomes clustered within participants.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

# Bayesian GLMM demonstration; not the same estimator as lme4::glmer
import statsmodels.api as sm
d["id"]=np.repeat(np.arange(70),4)
subject=rng.normal(size=70)
p=1/(1+np.exp(-(-.5+.8*d.x.to_numpy()+.6*subject[d.id.to_numpy()])))
d["y"]=rng.binomial(1,p)
fit=sm.BinomialBayesMixedGLM.from_formula("y ~ x",{"id":"0 + C(id)"},d).fit_vb()
print(fit.summary())
