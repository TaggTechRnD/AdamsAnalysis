Kaplan-Meier Analysis

Statistical method reference guide

Overview and appropriate use

Purpose

Kaplan-Meier analysis estimates the probability of remaining event-free over time using observed event times and right censoring.

Example research questions

What proportion of patients remain free of hospital readmission six months after discharge?

Design requirements

Time-to-event observations, event indicators, well-defined start and endpoint, and defensible censoring assumptions.

Strengths

Visualizes estimated event-free survival and accommodates right-censored follow-up.

Limitations

Does not adjust for multiple covariates in its basic form and is unreliable when censoring is informative.

When not to use it

Do not read the curve beyond the observed support or treat censoring as equivalent to experiencing an event.

Illustrative research scenario (hypothetical)

Plot six-month event-free survival after surgery for the full cohort.

Mathematical foundation

Mathematical foundation

survival estimator

\(\hat{S}(t)=\prod_{t_j\leq t}\left(1-\frac{d_j}{n_j}\right)\)
View LaTeX source
\hat{S}(t)=\prod_{t_j\leq t}\left(1-\frac{d_j}{n_j}\right)

Symbols

t_j: distinct event times; d_j: number of events at t_j; n_j: at-risk count just before t_j.

Explanation

The Kaplan–Meier estimator multiplies conditional survival probabilities across event times.

Important scope limitation

Independent/noninformative censoring is important; estimates become unstable with few at risk.

Assumptions and diagnostics

Assumptions and conditions

Event times, origin and status are correct; censoring is independent of the event process conditional on design, and subjects are appropriately sampled.

Diagnostics to perform

Audit event/censor coding and time origin; plot numbers at risk and censoring, check staggered entry and competing events.

Consequences of violations

Informative censoring biases survival probabilities; competing risks make 1 minus Kaplan-Meier survival unsuitable as a cause-specific cumulative incidence estimate.

Diagnostic caveats

Kaplan-Meier does not require proportional hazards. Independent censoring is a substantive assumption, not proven by a plotted curve.

Understanding the results

Primary outputs

Kaplan–Meier survival estimates S(t), numbers at risk, censor counts and median survival when estimable.

Inference and tests

Pointwise survival confidence intervals can be shown; group comparisons require a separate procedure such as log-rank test.

Effect sizes and intervals

Report survival probability at prespecified times with CI and median survival with CI when estimable.

Model fit and performance

Show numbers at risk and censoring pattern; an in-sample global model-fit statistic is not intrinsic.

Interpreting results

S(12 months)=0.8 estimates the fraction remaining event-free at 12 months under censoring assumptions.

Common mistakes

A Kaplan–Meier curve is not a causal treatment comparison; median survival may be not reached.

Example report wording (placeholder values)

At [time], estimated survival was [S] (95% CI [limits]); at risk = [n].

R tutorial

Learning goal

Estimate event-free probability over time by treatment arm.

Simulated data

Time-to-event outcomes with random right censoring and treatment/risk covariates.

Packages

survival

R example

set.seed(2026)
n <- 250
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
rate <- 0.08*exp(0.5*x - 0.5*treatment)
true_time <- rexp(n, rate=rate)
censor_time <- runif(n, 5, 22)
time <- pmin(true_time, censor_time)
event <- as.integer(true_time <= censor_time)
d <- data.frame(time, event, x, treatment)

fit<-survival::survfit(survival::Surv(time,event)~treatment,data=d)
print(summary(fit,times=c(5,10)))

Output to inspect

Kaplan–Meier survival estimates at specific times.

Limitations and checks

Requires non-informative censoring for conventional interpretation.

Python tutorial

Learning goal

Estimate event-free probability over time by treatment arm.

Simulated data

Time-to-event outcomes with random right censoring and treatment/risk covariates.

Packages

numpy, pandas, lifelines

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 250
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
rate = .08*np.exp(.5*x - .5*treatment)
true_time = rng.exponential(scale=1/rate)
censor_time = rng.uniform(5,22,n)
time = np.minimum(true_time,censor_time)
event = (true_time <= censor_time).astype(int)
d = pd.DataFrame({"time":time,"event":event,"x":x,"treatment":treatment})

# Install optional dependency beforehand: pip install lifelines
from lifelines import KaplanMeierFitter
for arm,part in d.groupby("treatment"):
    km=KaplanMeierFitter().fit(part.time,part.event,label=f"Arm {arm}")
    print(arm,km.survival_function_at_times([5,10]))
