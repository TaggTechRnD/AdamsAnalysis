Multiple Linear Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Multiple linear regression models a continuous outcome using several predictors simultaneously.

Example research questions

Is physical activity associated with fitness after accounting for age and smoking?

Design requirements

Continuous outcome with multiple predictors, appropriate functional forms, and sufficient information to estimate coefficients.

Strengths

Estimates adjusted associations and permits interactions and multivariable prediction.

Limitations

Collinearity, omitted variables, and mis-specified functional forms can destabilize or bias results.

When not to use it

Do not assume adjustment for measured covariates establishes causation or report coefficients without units and reference categories.

Illustrative research scenario (hypothetical)

Estimate associations of age, activity, and smoking with blood pressure.

Mathematical foundation

Mathematical foundation

linear model

\(Y_i=\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}+\varepsilon_i\)
View LaTeX source
Y_i=\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}+\varepsilon_i

Symbols

p: number of predictors; β_j: partial regression coefficients; ε: error.

Explanation

Models the mean outcome using several predictors simultaneously.

Important scope limitation

Coefficient interpretations are conditional on other included predictors; collinearity can increase uncertainty.

Assumptions and diagnostics

Assumptions and conditions

Correct functional form for each predictor; independent or appropriately modeled errors; full-rank design matrix without extreme collinearity.

Diagnostics to perform

Inspect residual plots, partial residual plots, VIF or condition indices, leverage/Cook distance, and dependence or heteroskedasticity.

Consequences of violations

Omitted nonlinear effects bias interpretation, collinearity destabilizes coefficients, and nonindependent errors invalidate ordinary standard errors.

Diagnostic caveats

No single VIF cut-off proves a model invalid. Adjusted associations need not be causal.

Understanding the results

Primary outputs

Regression coefficients, standard errors, model intercept and fitted predictions.

Inference and tests

Conditional coefficient t tests and overall F test may be reported with intervals and multiplicity awareness.

Effect sizes and intervals

Report adjusted effect per predictor with confidence interval, specifying held-constant covariates.

Model fit and performance

Adjusted R², residual diagnostics and validated RMSE quantify different aspects of fit/performance.

Interpreting results

Each coefficient represents an expected change in Y per unit X when other included covariates are fixed.

Common mistakes

Statistical significance does not imply practical importance; collinearity or omitted variables can undermine interpretation.

Example report wording (placeholder values)

Adjusted β[X] = [estimate] [units] (95% CI [lower], [upper]; p = [p]); adjusted R² = [R2adj].

R tutorial

Learning goal

Estimate adjusted slopes for several predictors and evaluate prediction error.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

stats

R example

set.seed(2026)
n <- 300
x1<-rnorm(n); x2<-rnorm(n); x3<-rnorm(n)
y<-3 + 2*x1 - x2 + 0.7*x3 + rnorm(n,sd=1.5)
d<-data.frame(y,x1,x2,x3)
idx<-sample(seq_len(n),round(.7*n))
train<-d[idx,];test<-d[-idx,]

fit<-lm(y~x1+x2+x3,data=train)
print(summary(fit))
print(mean((predict(fit,newdata=test)-test$y)^2))

Output to inspect

Coefficients, intervals, and held-out MSE.

Limitations and checks

Correlated predictors complicate attribution; training fit is not out-of-sample accuracy.

Python tutorial

Learning goal

Estimate adjusted slopes for several predictors and evaluate prediction error.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng=np.random.default_rng(2026)
n=300
x1=rng.normal(size=n);x2=rng.normal(size=n);x3=rng.normal(size=n)
y=3+2*x1-x2+.7*x3+rng.normal(0,1.5,n)
d=pd.DataFrame({"y":y,"x1":x1,"x2":x2,"x3":x3})
train,test=train_test_split(d,test_size=.3,random_state=2026)

import statsmodels.formula.api as smf
fit=smf.ols("y ~ x1+x2+x3",data=train).fit()
print(fit.summary())
print("Held-out MSE:",np.mean((fit.predict(test)-test.y)**2))
