ANCOVA

Statistical method reference guide

Overview and appropriate use

Purpose

Analysis of covariance (ANCOVA) compares adjusted group means or associations while accounting for one or more measured covariates.

Example research questions

Do treatment groups differ in follow-up blood pressure after accounting for baseline blood pressure?

Design requirements

Continuous outcome with categorical group factor and appropriate continuous or categorical covariates; plausible functional form and interpretation of covariate adjustment.

Strengths

Can improve precision in randomized studies and describe group differences at common covariate values.

Limitations

Results depend on model specification; covariate imbalance, interactions, and adjustment for post-treatment variables require care.

When not to use it

Do not assume covariate adjustment removes unmeasured confounding or automatically adjust for variables affected by treatment.

Illustrative research scenario (hypothetical)

Compare post-intervention fitness between randomized groups after adjusting for baseline fitness.

Mathematical foundation

Mathematical foundation

Y_i=\beta_0+\tau G_i+\beta_1X_i+\varepsilon_i

Symbols

Y: continuous outcome; G: group indicator; X: covariate; τ: adjusted group contrast.

Explanation

ANCOVA compares groups while adjusting for a preselected continuous covariate.

Important scope limitation

A shared covariate slope is assumed in this version; adjusting for post-treatment variables may bias causal estimates.

Assumptions and diagnostics

Assumptions and conditions

Continuous outcome; correctly coded groups and covariates; approximately linear covariate-outcome relation, independent errors and, for conventional ANCOVA, comparable covariate slopes between groups.

Diagnostics to perform

Plot outcome against covariate by group, fit or inspect group-by-covariate interaction, residual Q-Q and residual-versus-fit plots, and examine baseline covariate overlap.

Consequences of violations

Nonlinear associations or unequal slopes make an adjusted common group contrast misleading; poor overlap makes extrapolation unstable.

Diagnostic caveats

For randomized trials, choose adjustment covariates prospectively. Adjusting for post-treatment variables can bias causal comparisons.

Understanding the results

Primary outputs

Adjusted group means or contrast estimates, covariate coefficients, F/t statistics and p-values.

Inference and tests

Tests adjusted group differences conditional on specified covariates; model-based inference depends on correct specification.

Effect sizes and intervals

Report adjusted mean difference and confidence interval; optionally partial η² for the group factor.

Model fit and performance

Check linearity, residual structure, covariate overlap and homogeneity of slopes where assumed; model R² can supplement reporting.

Interpreting results

Adjusted differences compare groups at common model-defined covariate values.

Common mistakes

Adjustment alone does not remove unmeasured confounding; adjusting for a post-treatment variable can introduce bias.

Example report wording (placeholder values)

Adjusted mean difference = [diff] [units] (95% CI [lower], [upper]); F([df1], [df2]) = [F], p = [p].

R tutorial

Learning goal

Compare group means while adjusting for a continuous baseline covariate.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

fit<-lm(y ~ group + x,data=d)
print(summary(fit))
print(anova(fit))

Output to inspect

Adjusted group coefficient and CI.

Limitations and checks

Check slope homogeneity by considering a group×covariate term; adjustment alone does not remove confounding.

Compare group means while adjusting for a continuous baseline covariate.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.formula.api as smf
fit=smf.ols("y ~ C(group) + x",data=d).fit()
print(fit.summary())
