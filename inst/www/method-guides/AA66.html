k-Nearest Neighbors (kNN)

Statistical method reference guide

Overview and appropriate use

Purpose

k-nearest neighbors predicts a new observation from outcomes of nearby training observations under a selected distance metric.

Example research questions

Can patients with similar clinical profiles help predict a new patient's risk category?

Design requirements

Comparable feature measurements, an informative distance metric, feature scaling, a chosen neighborhood size, and a valid training-test split.

Strengths

Conceptually simple method that can represent irregular decision boundaries without fitting a parametric equation.

Limitations

Suffers in high dimensions and from irrelevant or poorly scaled features; prediction can be computationally expensive.

When not to use it

Do not use distances across incompatible feature scales without appropriate processing.

Illustrative research scenario (hypothetical)

Classify physical-activity profiles by similarity to previously labeled participants.

Mathematical foundation

Mathematical foundation

local prediction rule

\(\hat{y}(x)=\frac{1}{k}\sum_{i\in N_k(x)}y_i\)
View LaTeX source
\hat{y}(x)=\frac{1}{k}\sum_{i\in N_k(x)}y_i

Symbols

N_k(x): indices of the k nearest observations; k: chosen neighbor count.

Explanation

For regression, kNN predicts the average outcome among nearby training points.

Important scope limitation

Classification kNN uses voting; distance metric and feature scaling strongly affect results.

Assumptions and diagnostics

Assumptions and conditions

Chosen distance metric reflects meaningful similarity; features are scaled compatibly and neighborhood size k is tuned without leakage.

Diagnostics to perform

Check standardized feature ranges, sparse/high-dimensional effects, sensitivity across k, class balance, and held-out predictive performance.

Consequences of violations

Dominant units, wrong distance or small k amplify noise; very large k oversmooths local structure.

Diagnostic caveats

Curse-of-dimensionality can weaken neighbor interpretation even when code runs successfully.

Understanding the results

Primary outputs

Nearest-neighbor class votes or averaged predicted outcomes, distance metric and chosen k.

Inference and tests

kNN has no default coefficient p-values; quantify predictive uncertainty through separate validation/resampling.

Effect sizes and intervals

Report predicted class probability from neighbor votes only with calibration checks; regression effects are local prediction differences.

Model fit and performance

Held-out accuracy/AUC/log loss or RMSE/MAE, with tuning k and preprocessing performed within validation folds.

Interpreting results

A classification is determined by the classes of nearby training observations under the chosen distance.

Common mistakes

Predictions depend heavily on scaling, distance, class balance and leakage; kNN neighborhood proportion is not automatically calibrated.

Example report wording (placeholder values)

kNN k = [k], distance = [metric]; held-out [metric] = [value]; features scaled [method].

R tutorial

Learning goal

Classify a new record using nearby training observations.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

class

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

cols<-c("x1","x2","x3")
mu<-colMeans(train[,cols]); s<-apply(train[,cols],2,sd)
Xt<-scale(train[,cols],center=mu,scale=s)
Xv<-scale(test[,cols],center=mu,scale=s)
p<-class::knn(train=Xt,test=Xv,cl=train$y,k=7)
print(table(truth=test$y,predicted=p))

Python tutorial

Packages

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score
cols=["x1","x2","x3"]
fit=make_pipeline(StandardScaler(),KNeighborsClassifier(n_neighbors=7)).fit(train[cols],train.y)
print("Test accuracy:",accuracy_score(test.y,fit.predict(test[cols])))
