Beta Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Beta regression models a continuous fractional outcome bounded strictly between zero and one with flexible mean-variance behavior.

Example research questions

How does the proportion of a day spent sedentary vary with age and occupation?

Design requirements

Response is a continuous proportion in the open interval (0,1); predictors and link are appropriate, with boundary observations handled explicitly.

Strengths

Respects the bounded scale and accommodates heteroscedastic fractional data.

Limitations

Standard beta models cannot accept exact zeros or ones without a separate treatment; parameter interpretation is link dependent.

When not to use it

Do not directly fit an ordinary beta regression to proportions containing structural zero or one values.

Illustrative research scenario (hypothetical)

Model the fraction of monitored time spent physically active across participants.

Mathematical foundation

Mathematical foundation

Symbols

0<Y_i<1; μ_i: conditional mean; φ>0: precision.

Explanation

Models a continuous proportion or rate strictly between zero and one.

Important scope limitation

Exact zero and one observations require a modified model or separate treatment.

Assumptions and diagnostics

Assumptions and conditions

Outcome is a continuous proportion strictly between zero and one for ordinary beta regression; mean-link and precision/dispersion model suit the data.

Diagnostics to perform

Check observed zero/one values, fitted mean-variance patterns, quantile or simulation-based residuals and dispersion changes.

Consequences of violations

Boundary observations are outside the ordinary beta likelihood; wrong precision specification may distort uncertainty.

Diagnostic caveats

Do not silently replace exact 0 or 1 values with arbitrary nearby numbers; use a justified boundary-aware model or design.

Understanding the results

Primary outputs

Link-scale coefficients, fitted mean proportions and optional precision/dispersion parameter.

Inference and tests

Term tests and confidence intervals are model-dependent and often reported on link or response scale.

Effect sizes and intervals

Report predicted mean-proportion contrasts with intervals; exponentiated logit-link coefficients describe odds of the mean proportion.

Model fit and performance

Inspect fitted proportions, residuals, boundary values and model comparison criteria where suitable.

Interpreting results

A modeled rise from 0.30 to 0.35 is a five-percentage-point change in expected proportion.

Common mistakes

Standard beta regression excludes exact zero and one unless extended; coefficients are not raw proportion-point effects.

Example report wording (placeholder values)

Predicted mean proportion at X = [x1] was [p1] versus [p2] at [x2] (difference [delta], 95% CI [limits]).

R tutorial

Learning goal

Model a proportion strictly between zero and one.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

betareg

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

set.seed(2027)
d$prop<-rbeta(nrow(d),shape1=2+exp(.5*d$x),shape2=4)
fit<-betareg::betareg(prop~x,data=d)
print(summary(fit))

Output to inspect

Mean-link coefficient and precision/dispersion estimates.

Limitations and checks

Exact zeros or ones need a different model or justified boundary treatment.

Python tutorial

Learning goal

Model a proportion strictly between zero and one.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from statsmodels.othermod.betareg import BetaModel
prop=rng.beta(2+np.exp(.5*d.x.to_numpy()),4)
d["prop"]=prop
fit=BetaModel.from_formula("prop ~ x",data=d).fit(disp=False)
print(fit.summary())
