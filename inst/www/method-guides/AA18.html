Chi-Square Test of Independence

Statistical method reference guide

Overview and appropriate use

Purpose

Chi-square test of independence assesses whether two categorical variables are statistically associated in a contingency table.

Example research questions

Is vaccination status associated with age category?

Design requirements

Counts from a relevant sampling process, mutually exclusive cell assignments, and adequate expected frequencies for the chi-square approximation.

Strengths

Provides a familiar global test of association across categorical levels.

Limitations

Association is not causation, and sparse expected counts undermine the approximation.

When not to use it

Do not use percentages in place of counts or ignore matching, clustering, or very sparse cells.

Illustrative research scenario (hypothetical)

Test association between smoking status and employment category.

Mathematical foundation

Mathematical foundation

test statistic

\(\chi^2=\sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}},\quad E_{ij}=\frac{n_{i\cdot}n_{\cdot j}}{n}\)
View LaTeX source
\chi^2=\sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}},\quad E_{ij}=\frac{n_{i\cdot}n_{\cdot j}}{n}

Symbols

O_ij: observed cell count; E_ij: expected cell count under independence; n: total count.

Explanation

Compares the observed table to expected counts assuming the categorical variables are independent.

Important scope limitation

Sparse expected counts compromise the chi-square approximation; consider an exact procedure when appropriate.

Assumptions and diagnostics

Assumptions and conditions

Categories and counts are correctly defined, units are independent, and expected frequencies are sufficient for the selected chi-square approximation.

Diagnostics to perform

Build a contingency table with expected counts, inspect structural zeros, sparse cells, duplicates, and whether observations appear in multiple cells.

Consequences of violations

Small expected counts impair asymptotic p-value accuracy; correlated observations produce incorrect uncertainty estimates.

Diagnostic caveats

No universal single expected-count threshold applies to every table. Exact or simulation-based procedures may be preferable for sparse data.

Understanding the results

Primary outputs

Contingency table, Pearson chi-square statistic, degrees of freedom and p-value.

Inference and tests

Tests statistical independence of categorical variables; expected-cell counts affect approximation quality.

Effect sizes and intervals

Report Cramér V (and, for 2×2 tables, risk/odds contrasts where scientifically relevant) with uncertainty if available.

Model fit and performance

Check expected counts, missingness and independence; no prediction-model fit measure is inherent.

Interpreting results

Association means observed category combinations differ from independence expectations.

Common mistakes

A significant chi-square says nothing alone about effect size, direction, or causality.

Example report wording (placeholder values)

χ²([df], N = [N]) = [stat], p = [p], Cramér V = [V].

R tutorial

Learning goal

Evaluate association between two categorical variables.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

ct<-table(d$treatment,d$y)
print(ct)
print(chisq.test(ct))

Output to inspect

Observed/expected counts and Pearson chi-square test.

Limitations and checks

Review expected counts; chi-square does not quantify effect magnitude.

Learning goal

Evaluate association between two categorical variables.

Simulated data

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

from scipy import stats
ct=pd.crosstab(d.treatment,d.y)
print(ct)
print(stats.chi2_contingency(ct))
