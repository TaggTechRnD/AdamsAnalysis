Confirmatory Factor Analysis (CFA)

Statistical method reference guide

Overview and appropriate use

Purpose

Confirmatory factor analysis tests whether observed item covariance agrees with a prespecified latent measurement structure.

Example research questions

Do questionnaire items fit the hypothesized three-domain wellbeing model?

Design requirements

Predefined factor structure, appropriate item-level measures and estimator, sufficient sample information, and identifiable model.

Strengths

Tests an explicit measurement theory and estimates item loadings and model-fit summaries.

Limitations

Good fit does not prove construct validity, measurement invariance, or causal relationships.

When not to use it

Do not describe a heavily modified post hoc model as an independent confirmation without validation.

Illustrative research scenario (hypothetical)

Test whether twelve health-literacy questions load onto three predefined domains.

Mathematical foundation

Mathematical foundation

confirmatory factor model

\(\boldsymbol{x}=\Lambda\boldsymbol{f}+\boldsymbol{\epsilon},\qquad \Sigma=\Lambda\Phi\Lambda^\top+\Theta\)
View LaTeX source
\boldsymbol{x}=\Lambda\boldsymbol{f}+\boldsymbol{\epsilon},\qquad \Sigma=\Lambda\Phi\Lambda^\top+\Theta

Symbols

Λ: hypothesized factor-loading matrix; Φ: latent covariance; Θ: measurement-error covariance.

Explanation

Tests a prespecified factor-loading structure against observed covariance patterns.

Important scope limitation

Identification and model fit must be checked; high fit does not establish construct validity alone.

Assumptions and diagnostics

Assumptions and conditions

The factor structure is specified before model fitting; model is identifiable, measurement scales/estimators are appropriate, and sample information supports estimation.

Diagnostics to perform

Check identification and convergence, standardized loadings, residual covariance, fit indices (CFI, TLI, RMSEA, SRMR) and distribution-sensitive estimation.

Consequences of violations

Misidentification or incompatible estimators prevent meaningful interpretation; poor fit or weak loadings undermine the proposed measurement model.

Diagnostic caveats

Good global fit alone does not prove construct validity or measurement invariance across groups.

Understanding the results

Primary outputs

Standardized factor loadings, latent-factor correlations, standard errors and model fit indices.

Inference and tests

Model chi-square tests exact-fit null; loading tests and CIs depend on estimator and identification.

Effect sizes and intervals

Report loadings and confidence intervals, factor correlations and meaningful reliability evidence.

Model fit and performance

CFI/TLI, RMSEA with CI and SRMR summarize different misfit aspects; threshold cutoffs are context-dependent.

Interpreting results

A high loading indicates an indicator tracks its modeled latent factor after accounting for its scale.

Common mistakes

Good global fit alone does not prove construct validity or population measurement invariance.

Example report wording (placeholder values)

CFA: χ²([df]) = [stat], CFI = [CFI], TLI = [TLI], RMSEA = [RMSEA] (90% CI [limits]), SRMR = [SRMR].

R tutorial

Learning goal

Confirm a prespecified two-factor measurement model.

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

lavaan

R example

set.seed(2026)
n <- 240
f1 <- rnorm(n); f2 <- 0.3*f1 + rnorm(n)
d <- data.frame(
  a1=0.9*f1+rnorm(n,sd=.5), a2=0.8*f1+rnorm(n,sd=.6),
  a3=0.7*f1+rnorm(n,sd=.6), b1=0.9*f2+rnorm(n,sd=.5),
  b2=0.8*f2+rnorm(n,sd=.6), b3=0.7*f2+rnorm(n,sd=.6))

model <- 'F1 =~ a1 + a2 + a3
F2 =~ b1 + b2 + b3'
fit <- lavaan::cfa(model,data=d,std.lv=TRUE)
print(lavaan::fitMeasures(fit,c("cfi","tli","rmsea","srmr")))
print(lavaan::standardizedSolution(fit))

Output to inspect

Standardized loadings and global model fit statistics.

Limitations and checks

Good global fit alone does not establish measurement validity; check identification and residuals.

Python tutorial

Learning goal

Confirm a prespecified two-factor measurement model.

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

numpy, pandas, semopy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 240
f1 = rng.normal(size=n); f2 = .3*f1 + rng.normal(size=n)
d = pd.DataFrame({
 "a1":.9*f1+rng.normal(0,.5,n), "a2":.8*f1+rng.normal(0,.6,n),
 "a3":.7*f1+rng.normal(0,.6,n), "b1":.9*f2+rng.normal(0,.5,n),
 "b2":.8*f2+rng.normal(0,.6,n), "b3":.7*f2+rng.normal(0,.6,n)})

# Install optional dependency beforehand: pip install semopy
from semopy import Model, calc_stats
model="F1 =~ a1 + a2 + a3\nF2 =~ b1 + b2 + b3"
fit=Model(model)
fit.fit(d)
print(calc_stats(fit).loc[["Value"], ["CFI","TLI","RMSEA"]])
print(fit.inspect())
