DBSCAN

Statistical method reference guide

Overview and appropriate use

Purpose

DBSCAN groups points that occupy dense neighborhoods and labels isolated points as noise.

Example research questions

Are there spatial concentrations of disease events with irregular shapes?

Design requirements

An informative distance metric, scale or neighborhood radius, minimum-neighbor criterion, and comparable feature scaling.

Strengths

Finds irregularly shaped dense clusters and can explicitly label noise points.

Limitations

Sensitive to neighborhood settings and struggles when densities differ widely; a detected cluster is not automatically statistically significant.

When not to use it

Do not interpret density clusters as proof of a disease hotspot without considering population at risk and ascertainment.

Illustrative research scenario (hypothetical)

Identify dense geographic concentrations of service requests in a city.

Mathematical foundation

Mathematical foundation

density rule

\(N_{\varepsilon}(x)=\{y:d(x,y)\leq\varepsilon\},\quad x\ \mathrm{core}\iff |N_{\varepsilon}(x)|\geq\mathrm{minPts}\)
View LaTeX source
N_{\varepsilon}(x)=\{y:d(x,y)\leq\varepsilon\},\quad x\ \mathrm{core}\iff |N_{\varepsilon}(x)|\geq\mathrm{minPts}

Symbols

ε: radius; minPts: required neighborhood count; d: distance metric.

Explanation

DBSCAN defines dense regions using core points and density-reachable neighbors.

Important scope limitation

The neighborhood definition typically includes the point itself; ε and minPts affect clusters and noise labels.

Assumptions and diagnostics

Assumptions and conditions

Distance metric and density parameters suit scaled features; clusters are expected to form locally dense regions separated by sparser regions.

Diagnostics to perform

Inspect k-distance curve, sensitivity to epsilon/minPts and scaling, proportion labeled noise, and stability across parameter choices.

Consequences of violations

Wrong radius or scaling merges distinct clusters or marks legitimate records as noise; variable-density populations can be poorly represented.

Diagnostic caveats

DBSCAN labels points as noise according to density choices, not because they are necessarily errors or anomalies.

Understanding the results

Primary outputs

Core, border and noise labels, cluster sizes and hyperparameters epsilon/minPts.

Inference and tests

DBSCAN is unsupervised and does not inherently produce significance tests or parameter intervals.

Effect sizes and intervals

Report cluster composition, noise fraction and stability under reasonable parameter perturbations.

Model fit and performance

Density-cluster stability and domain usefulness matter; silhouette is sometimes misleading for non-convex or noise-rich clusters.

Interpreting results

Noise points were not assigned to a sufficiently dense region under the selected distance and parameters.

Common mistakes

A noise label does not prove an observation is an error or anomaly; results depend on density scale and metric.

Example report wording (placeholder values)

DBSCAN ε = [epsilon], minPts = [n]; clusters = [k], noise fraction = [percent]%; stability = [result].

R tutorial

Learning goal

Detect density-connected clusters and possible noise points.

Simulated data

180 unlabeled observations from three well-separated feature clusters.

Packages

dbscan

R example

set.seed(2026)
X <- rbind(matrix(rnorm(120, mean=-2, sd=.5), ncol=2),
           matrix(rnorm(120, mean=2, sd=.5), ncol=2),
           cbind(rnorm(60,mean=2,sd=.5),rnorm(60,mean=-2,sd=.5)))
colnames(X)<-c("feature1","feature2")

fit<-dbscan::dbscan(scale(X),eps=.5,minPts=5)
print(table(fit$cluster)) # 0 denotes noise

Output to inspect

Cluster labels and number of unassigned/noise points.

Limitations and checks

Distance scale, epsilon and minimum-neighbor settings govern results.

Python example

import numpy as np
rng=np.random.default_rng(2026)
X=np.vstack([rng.normal(-2,.5,(60,2)),rng.normal(2,.5,(60,2)),
             np.column_stack([rng.normal(2,.5,60),rng.normal(-2,.5,60)])])

from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler
fit=DBSCAN(eps=.5,min_samples=5).fit(StandardScaler().fit_transform(X))
print("Labels (-1 noise):",np.unique(fit.labels_,return_counts=True))
