Spearman Correlation

Statistical method reference guide

Overview and appropriate use

Purpose

Spearman correlation summarizes monotonic association using ranks rather than raw measurements.

Example research questions

As symptom severity ranks increase, do quality-of-life scores tend to decrease?

Design requirements

Paired ordinal or quantitative observations; a monotonic relationship is the relevant target, with ties handled appropriately.

Strengths

Useful for ordinal variables and less sensitive than Pearson correlation to extreme measured values.

Limitations

Does not quantify the size of changes in original units; not designed to capture nonmonotonic patterns.

When not to use it

Do not interpret a strong rank correlation as evidence of a linear relationship or causation.

Illustrative research scenario (hypothetical)

Assess whether ranked physical-activity levels track ordered self-rated health.

Mathematical foundation

Mathematical foundation

association statistic

\(\rho_s=\operatorname{cor}(R_x,R_y)\)
View LaTeX source
\rho_s=\operatorname{cor}(R_x,R_y)

Symbols

R_x, R_y: ranks of the observed x and y values (average ranks for ties).

Explanation

Spearman correlation applies Pearson correlation to ranked variables, capturing monotonic relationships.

Important scope limitation

The shortcut 1−6Σd²/[n(n²−1)] is exact only without ties.

Assumptions and diagnostics

Assumptions and conditions

Observations are paired and independent across sampling units for standard inference. Rank ordering is meaningful; a monotone trend is needed for a strong single-number summary.

Diagnostics to perform

Draw a scatterplot with ranks or smoothing, assess monotonicity, ties and influential clusters, and check whether repeated measurements were treated as independent.

Consequences of violations

Nonmonotonic associations may give a near-zero Spearman coefficient despite a substantial relationship; many ties affect precision and test approximations.

Diagnostic caveats

Spearman correlation does not assume normal data or require a monotonic relation to be calculated; monotonicity matters to interpretation.

Understanding the results

Primary outputs

Spearman rank correlation ρ (rho), sample size and rank scatterplot.

Inference and tests

A test of no monotonic association yields a p-value; exact or approximate methods depend on sample size and ties.

Effect sizes and intervals

ρ ranges from −1 to +1; report an appropriate uncertainty interval if inferential interpretation is intended.

Model fit and performance

Inspect monotonicity, ties, and influential rankings; conventional model fit indices do not apply.

Interpreting results

Positive ρ suggests observations with higher X tend to rank higher on Y.

Common mistakes

It does not measure linear change per unit, prove causation, or reliably capture a U-shaped relationship.

Example report wording (placeholder values)

Spearman ρ = [rho] (n = [n], p = [p]); ties were [handled/how].

R tutorial

Learning goal

Estimate monotonic association based on ranks.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

print(cor.test(d$x,d$y,method="spearman",exact=FALSE))

Output to inspect

Spearman rho and p-value.

Limitations and checks

A monotonic trend is not necessarily linear or causal.

Python tutorial

Learning goal

Estimate monotonic association based on ranks.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
print(stats.spearmanr(d.x,d.y))
