Confidence Intervals

Statistical method reference guide

Overview and appropriate use

Purpose

Confidence intervals provide a range of parameter values compatible with an estimator and its uncertainty under an assumed statistical procedure.

Example research questions

What range of plausible population prevalences is consistent with the observed survey data?

Design requirements

A clearly defined estimand, relevant estimator and uncertainty model, and appropriate sampling or design assumptions.

Strengths

Communicates estimation precision and magnitude rather than only a significance decision.

Limitations

Coverage depends on assumptions and method choice; a 95 percent interval does not assign 95 percent probability to a fixed parameter in frequentist interpretation.

When not to use it

Do not confuse a confidence interval with a prediction interval or interpret it as the range containing 95 percent of individual observations.

Illustrative research scenario (hypothetical)

Report a 95 percent interval for the difference in average blood pressure between treatment groups.

Mathematical foundation

Mathematical foundation

interval estimation

\(\widehat{\theta}\pm z_{1-\alpha/2}\,\widehat{SE}(\widehat{\theta})\)
View LaTeX source
\widehat{\theta}\pm z_{1-\alpha/2}\,\widehat{SE}(\widehat{\theta})

Symbols

theta-hat: estimate; z: standard-normal critical value; SE: estimated standard error; 1−α: nominal coverage.

Explanation

A common large-sample Wald interval expresses sampling uncertainty around a parameter estimate.

Important scope limitation

Not a universal CI formula; small samples, proportions, skewed estimators, and complex designs often need other intervals.

Assumptions and diagnostics

Assumptions and conditions

The population quantity (estimand), estimator and interval procedure are specified. Sampling, dependence and distributional conditions must support the claimed coverage.

Diagnostics to perform

Verify standard error calculation or bootstrap design, inspect sampling weights, clusters, small-cell counts, skew and boundary estimates; simulate coverage when feasible.

Consequences of violations

Ignoring dependence, selective sampling or skew can produce intervals that undercover the target quantity.

Diagnostic caveats

A 95% frequentist confidence interval is a procedure with nominal long-run coverage, not a 95% probability the fixed parameter lies in this observed interval.

Understanding the results

Primary outputs

Point estimate, confidence level, confidence interval limits, and interval construction method.

Inference and tests

Confidence intervals quantify long-run coverage of the interval procedure under its assumptions; an interval is not itself a hypothesis test.

Effect sizes and intervals

Interval width reflects uncertainty about a specified estimand; choose a defensible method for means, proportions, differences or other targets.

Model fit and performance

Check the estimator, dependence, weighting, sample size and method coverage; no model fit index is intrinsic.

Interpreting results

A 95% procedure would include the true fixed estimand in about 95% of repeated samples under its assumptions.

Common mistakes

Do not say a realized frequentist 95% interval gives a 95% probability that the fixed parameter lies inside it.

Example report wording (placeholder values)

[Estimand] = [estimate] (95% CI [lower], [upper]; method = [interval method]).

R tutorial

Learning goal

Calculate a 95% confidence interval for a population mean under sampling assumptions.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

print(t.test(d$y,conf.level=.95)$conf.int)

Output to inspect

Lower and upper confidence limits.

Limitations and checks

The 95% interval is not a 95% probability interval for individual outcomes.

Python tutorial

Learning goal

Calculate a 95% confidence interval for a population mean under sampling assumptions.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
m=d.y.mean(); se=d.y.sem();df=len(d)-1
print(stats.t.interval(.95,df,loc=m,scale=se))
