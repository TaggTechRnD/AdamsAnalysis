Partial Correlation

Statistical method reference guide

Overview and appropriate use

Purpose

Partial correlation describes the residual association between two variables after adjusting linearly for specified covariates.

Example research questions

Are sleep duration and attention associated after adjusting for age?

Design requirements

Numeric target variables, specified adjustment variables, and an appropriate conditional linear relationship.

Strengths

Summarizes an adjusted association in standardized form.

Limitations

Sensitive to covariate choice, measurement error, and nonlinear confounding.

When not to use it

Do not assume conditioning removes unmeasured confounding or that a partial correlation identifies a causal pathway.

Illustrative research scenario (hypothetical)

Examine the association between activity and fitness after adjusting for age and body mass index.

Mathematical foundation

Mathematical foundation

association statistic

\(r_{xy\cdot z}=\frac{r_{xy}-r_{xz}r_{yz}}{\sqrt{(1-r_{xz}^2)(1-r_{yz}^2)}}\)
View LaTeX source
r_{xy\cdot z}=\frac{r_{xy}-r_{xz}r_{yz}}{\sqrt{(1-r_{xz}^2)(1-r_{yz}^2)}}

Symbols

r_ab: Pearson correlation between a and b; z: a single adjustment variable.

Explanation

Measures residual linear association between x and y after adjusting for z.

Important scope limitation

This expression covers one adjustment variable; partial correlation does not remove unmeasured confounding.

Assumptions and diagnostics

Assumptions and conditions

Two target variables and relevant adjustment covariates are correctly specified. Standard partial correlation assumes an appropriate residual association model and independent units.

Diagnostics to perform

Inspect pairwise and residual scatterplots, nonlinear patterns, collinearity, influence points and rationale for covariate selection.

Consequences of violations

Missed nonlinear effects or inappropriate covariate control produce misleading partial associations, potentially opening collider bias.

Diagnostic caveats

Covariate choice is a causal-design judgment and cannot be validated by goodness-of-fit tests alone.

Understanding the results

Primary outputs

Partial correlation r between two variables conditional on specified covariates.

Inference and tests

Tests and confidence intervals are conditional on adjustment set and model assumptions.

Effect sizes and intervals

Report partial r and confidence interval alongside the exact covariate set.

Model fit and performance

Examine linearity, residual dependence, covariate quality and sensitivity to adjustment; no universal goodness-of-fit statistic.

Interpreting results

Partial r measures remaining linear association after removing modeled associations with selected covariates.

Common mistakes

Partialling out covariates does not automatically identify a causal relationship; adjusting for colliders can create bias.

Example report wording (placeholder values)

Partial r(X,Y | [covariates]) = [r] (95% CI [lower], [upper], p = [p]).

R tutorial

Learning goal

Estimate the linear x–y correlation after adjusting for group.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

# Residualize y and x against an observed covariate: group
rx<-resid(lm(x~group,data=d))
ry<-resid(lm(y~group,data=d))
r<-cor(rx,ry); df<-length(rx)-3
stat<-r*sqrt(df/(1-r^2))
print(c(partial_r=r, df=df, p_value=2*pt(-abs(stat),df=df)))

Output to inspect

Partial correlation coefficient; note residualization.

Limitations and checks

For formal inference accounting for control variables, adjust degrees of freedom (naive residual correlation p-value does not).

Python tutorial

Learning goal

Estimate the linear x–y correlation after adjusting for group.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.formula.api as smf
from scipy import stats
rx=smf.ols("x ~ C(group)",data=d).fit().resid
ry=smf.ols("y ~ C(group)",data=d).fit().resid
r=np.corrcoef(rx,ry)[0,1]
df=len(rx)-3
stat=r*np.sqrt(df/(1-r**2))
print({"partial_r":r,"df":df,"p_value":2*stats.t.sf(abs(stat),df)})
