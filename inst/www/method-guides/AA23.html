Poisson Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Poisson regression models an expected count or event rate using a log link, optionally with an offset for exposure time.

Example research questions

Do monthly emergency visits vary with environmental exposure after accounting for population size?

Design requirements

Nonnegative count outcomes, an appropriate observation period or offset for rates, and a plausible count-process model.

Strengths

Handles count outcomes and rates while preserving their nonnegative scale.

Limitations

Overdispersion, excess zeros, temporal dependence, and unmeasured exposure differences can compromise simple Poisson inference.

When not to use it

Do not treat an event count as an event rate without the relevant exposure denominator or ignore severe overdispersion.

Illustrative research scenario (hypothetical)

Model weekly asthma admissions using an offset for the population at risk.

Mathematical foundation

Mathematical foundation

generalized linear model

\(Y_i\sim\mathrm{Poisson}(\mu_i),\qquad \log(\mu_i)=\boldsymbol{x}_i^\top\boldsymbol{\beta}\)
View LaTeX source
Y_i\sim\mathrm{Poisson}(\mu_i),\qquad \log(\mu_i)=\boldsymbol{x}_i^\top\boldsymbol{\beta}

Symbols

μ_i: expected count; x_i: covariate vector; β: log-rate or log-count coefficients depending on offsets.

Explanation

Models expected event counts or rates using a log link.

Important scope limitation

Poisson variance equals its mean; overdispersion and exposure offsets require evaluation.

Assumptions and diagnostics

Assumptions and conditions

Nonnegative integer event counts with correctly defined exposure times or offsets; Poisson mean-variance relation conditional on predictors and suitable dependence structure.

Diagnostics to perform

Check count frequencies, zero counts, deviance and Pearson dispersion, residuals versus fitted values, offsets, and within-unit clustering.

Consequences of violations

Overdispersion gives overly narrow standard errors and false positives; excess zeros, unmodeled dependence, or omitted exposure offsets distort estimates.

Diagnostic caveats

Excess zeros alone do not prove a zero-inflated data-generating process; assess alternative count models and data collection.

Understanding the results

Primary outputs

Log-rate coefficients, incidence rate ratios (IRRs), predicted counts and exposure-offset specification.

Inference and tests

Coefficient Wald/LR tests and confidence intervals apply under a specified count process.

Effect sizes and intervals

IRR with confidence interval describes multiplicative rates/count expectations conditional on model covariates and offset.

Model fit and performance

Assess overdispersion, excess zeros, residuals and predictive calibration; deviance/AIC are comparative, not absolute proof of fit.

Interpreting results

IRR 1.2 suggests an expected event rate 20% higher at the specified contrast.

Common mistakes

Ignoring unequal exposure times or substantial overdispersion can make results misleading; IRR is not a probability ratio.

Example report wording (placeholder values)

IRR for [X] = [IRR] (95% CI [lower], [upper]); exposure offset = [unit]; dispersion check = [result].

R tutorial

Learning goal

Model event rates with person-time/exposure offset.

Simulated data

Counts observed over differing exposure durations with an association between rate and covariate.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
exposure <- runif(n, 0.5, 2)
mu <- exp(0.5 + 0.6*x + log(exposure))
y <- rpois(n, lambda = mu)
d <- data.frame(y, x, exposure)

fit<-glm(y~x+offset(log(exposure)),family=poisson(),data=d)
print(summary(fit))
print(exp(coef(fit)))

Output to inspect

Rate ratio exp(beta) and fit diagnostics.

Limitations and checks

Assess overdispersion and excess zeros; offset assumes coefficient fixed at one.

Python tutorial

Learning goal

Model event rates with person-time/exposure offset.

Simulated data

Counts observed over differing exposure durations with an association between rate and covariate.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
exposure = rng.uniform(.5, 2, n)
mu = np.exp(.5 + .6*x + np.log(exposure))
y = rng.poisson(mu)
d = pd.DataFrame({"y":y,"x":x,"exposure":exposure})

import statsmodels.formula.api as smf
import statsmodels.api as sm
fit=smf.glm("y ~ x",data=d,family=sm.families.Poisson(),
            offset=np.log(d.exposure)).fit()
print(fit.summary())
print("Rate ratios:\n",np.exp(fit.params))
