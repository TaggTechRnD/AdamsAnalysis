Negative Binomial Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Negative binomial regression models event counts allowing variance to exceed the mean through an overdispersion parameter.

Example research questions

Are asthma admission rates associated with pollution when daily counts are overdispersed?

Design requirements

Nonnegative counts, a suitable exposure offset for rates, and evidence that the chosen negative-binomial form is reasonable.

Strengths

Better accommodates extra-Poisson variation than standard Poisson regression.

Limitations

Does not automatically correct zero inflation, serial correlation, or confounding.

When not to use it

Do not select it solely because counts are present without checking whether the assumed count process is suitable.

Illustrative research scenario (hypothetical)

Model monthly emergency-department visits when variability exceeds that expected under a Poisson model.

Mathematical foundation

Mathematical foundation

count regression model

\(\log(\mu_i)=\boldsymbol{x}_i^\top\boldsymbol{\beta},\qquad \mathrm{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2\)

\log(\mu_i)=\boldsymbol{x}_i^\top\boldsymbol{\beta},\qquad \mathrm{Var}(Y_i\mid x_i)=\mu_i+\alpha\mu_i^2

Symbols

μ_i: mean count; α>0: overdispersion parameter (NB2 formulation).

Explanation

Negative-binomial regression allows count variance to exceed the mean.

Important scope limitation

The displayed variance is NB2, one of several parameterizations; offsets may be needed for varying exposure.

Assumptions and diagnostics

Assumptions and conditions

Nonnegative counts and appropriate exposure offsets; conditional count variance can exceed its mean and dependence is appropriately handled.

Diagnostics to perform

Inspect mean-variance relation, Pearson residual dispersion, zero frequency, fitted versus observed count distributions and offset correctness.

Consequences of violations

Incorrect dispersion or unmodeled structural zeros can bias fit and uncertainty; forgetting exposure time invalidates rates.

Diagnostic caveats

Negative binomial handles a particular form of overdispersion; it is not automatically preferred for all zero-heavy datasets.

Understanding the results

Primary outputs

Log-mean coefficients, IRRs, dispersion parameter and predicted event counts.

Inference and tests

Wald/LR tests and intervals quantify term uncertainty under a specified negative-binomial parameterization.

Effect sizes and intervals

IRR and interval describe expected multiplicative count/rate changes; specify any exposure offset.

Model fit and performance

Check dispersion, residuals and zero frequencies; AIC/deviance can compare suitable count models.

Interpreting results

IRR 0.8 indicates 20% lower expected event rate for the named contrast with other covariates held fixed.

Common mistakes

Negative binomial is not automatically needed for every count outcome; dispersion parameter meanings differ among implementations.

Example report wording (placeholder values)

Negative-binomial IRR([X]) = [IRR] (95% CI [limits]); dispersion = [parameter]; offset = [exposure].

R tutorial

Learning goal

Model overdispersed event counts.

Simulated data

Overdispersed counts: variance exceeds the mean.

Packages

MASS

R example

set.seed(2026)
n <- 300
x <- rnorm(n)
mu <- exp(0.4 + 0.55*x)
y <- rnbinom(n, size = 1.2, mu = mu)
d <- data.frame(y, x)

fit<-MASS::glm.nb(y~x,data=d)
print(summary(fit))
print(exp(coef(fit)))

Output to inspect

Log count ratio, dispersion parameter and model uncertainty.

Limitations and checks

Compare with Poisson dispersion; NB models do not automatically handle excess structural zeros.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 300
x = rng.normal(size=n)
mu = np.exp(.4 + .55*x)
y = rng.negative_binomial(1.2, 1.2/(1.2+mu))
d = pd.DataFrame({"y":y,"x":x})

import statsmodels.formula.api as smf
fit=smf.negativebinomial("y ~ x",data=d).fit(disp=False)
print(fit.summary())
