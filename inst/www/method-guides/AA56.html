Latent Growth Curve Modeling

Statistical method reference guide

Overview and appropriate use

Purpose

Latent growth curve models use repeated observations to estimate average change trajectories and between-person variation in starting levels and growth.

Example research questions

Do adolescents differ in how quickly their fitness changes over several years?

Design requirements

Repeated outcomes across meaningful timepoints, an identifiable growth specification, and enough repeated information for chosen random variation.

Strengths

Separates initial status from change and can model predictors of growth trajectories.

Limitations

Inference depends on chosen trajectory form, measurement invariance when latent measures are used, and missingness assumptions.

When not to use it

Do not assume linear growth without checking its substantive plausibility or infer individual causal trends from observational trajectories.

Illustrative research scenario (hypothetical)

Model changes in psychological wellbeing across five annual survey waves.

Mathematical foundation

Mathematical foundation

latent trajectory model

\(Y_{it}=\eta_{0i}+\eta_{1i}t+\varepsilon_{it}\)
View LaTeX source
Y_{it}=\eta_{0i}+\eta_{1i}t+\varepsilon_{it}

Symbols

η0i: person-specific latent intercept; η1i: latent growth slope; t: time; ε: measurement residual.

Explanation

Models individual baseline levels and trajectories using latent growth factors.

Important scope limitation

This is the linear-growth case; irregular time, nonlinear growth and missingness need appropriate specification.

Assumptions and diagnostics

Assumptions and conditions

Repeated measures align to a meaningful time scale; trajectory functional form and growth-factor structure are identifiable with suitable missing-data assumptions.

Diagnostics to perform

Plot subject trajectories, inspect time coding and loading constraints, test alternative growth forms, review model fit, and examine attrition patterns.

Consequences of violations

Wrong trajectory shape or selective dropout can misstate average growth and between-person variability.

Diagnostic caveats

Growth curves do not by themselves establish causal effects. Measurement invariance may matter for latent constructs measured over time.

Understanding the results

Primary outputs

Estimated latent intercept/slope means, factor variances/covariances and trajectory-class predictors where specified.

Inference and tests

Tests and intervals quantify growth-factor parameters under trajectory and missing-data assumptions.

Effect sizes and intervals

Report mean rate of change with CI, between-person variance in slopes and key model contrasts.

Model fit and performance

Compare identified models with CFI/TLI, RMSEA/SRMR where applicable and likelihood criteria for comparable fits.

Interpreting results

Positive mean latent slope means the population trajectory generally increases per chosen time unit.

Common mistakes

Assuming linear growth when trajectories curve can mislead; model fit does not establish causal influences on growth.

Example report wording (placeholder values)

Mean latent slope = [estimate] [units/time] (95% CI [limits]); slope variance = [var]; CFI = [value].

R tutorial

Learning goal

Represent repeated outcomes via latent intercept and linear change factors.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

lavaan

R example

set.seed(2026)
n <- 90
d <- expand.grid(id = seq_len(n), time = factor(c("Baseline","Week6","Week12"),
                 levels=c("Baseline","Week6","Week12")))
d$group <- factor(ifelse(d$id <= n/2, "Control", "Treatment"))
subject_effect <- rnorm(n, sd = 3)
d$y <- 30 + subject_effect[d$id] + 1.2*(as.integer(d$time)-1) +
  2*(d$group == "Treatment")*(as.integer(d$time)-1) + rnorm(nrow(d), sd=2)

wide<-reshape(d[,c("id","time","y")],idvar="id",timevar="time",direction="wide")
names(wide)<-sub("y[.]","y_",names(wide))
model <- 'i =~ 1*y_Baseline + 1*y_Week6 + 1*y_Week12
  s =~ 0*y_Baseline + 1*y_Week6 + 2*y_Week12
  i ~~ s'
fit<-lavaan::growth(model,data=wide)
print(lavaan::parameterEstimates(fit))

Output to inspect

Mean and variation of growth factors, where estimated.

Limitations and checks

Growth identification and mean structure require special care; semopy Model does not exactly replicate lavaan::growth.

Learning goal

Simulated data

Packages

numpy, pandas, semopy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
d = pd.MultiIndex.from_product([range(n), ["Baseline","Week6","Week12"]],
                               names=["id","time"]).to_frame(index=False)
d["group"] = np.where(d.id < n // 2, "Control", "Treatment")
subject_effect = rng.normal(0, 3, n)
t = d.time.map({"Baseline": 0, "Week6": 1, "Week12": 2}).to_numpy()
d["y"] = (30 + subject_effect[d.id.to_numpy()] + 1.2*t +
          2*(d.group.to_numpy() == "Treatment")*t + rng.normal(0,2,len(d)))

# Install optional dependency beforehand: pip install semopy
from semopy import Model
wide=d.pivot(index="id",columns="time",values="y")
wide=wide[["Baseline","Week6","Week12"]].copy()
wide.columns=["y_0","y_1","y_2"]
# Demonstrates an SEM-based growth specification; estimator differs from lavaan::growth
model="i =~ 1*y_0 + 1*y_1 + 1*y_2\ns =~ 0*y_0 + 1*y_1 + 2*y_2\ni ~~ s"
fit=Model(model)
fit.fit(wide)
print(fit.inspect())
