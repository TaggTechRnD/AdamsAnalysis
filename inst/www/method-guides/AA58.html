Exponential Smoothing (ETS)

Statistical method reference guide

Overview and appropriate use

Purpose

Exponential smoothing state-space methods forecast a time series by updating estimates of level, trend, and optionally seasonality.

Example research questions

What are likely next-quarter clinic volumes given recent trends and seasonal patterns?

Design requirements

Regularly ordered time-series observations with sufficient history for the chosen trend and seasonal structure.

Strengths

Parsimonious, interpretable forecasts that often work well for stable level-trend-seasonal patterns.

Limitations

Cannot by itself explain causal drivers; abrupt structural changes can substantially impair forecast accuracy.

When not to use it

Do not treat a strong forecast as evidence about why the series changed or ignore rolling-origin validation.

Illustrative research scenario (hypothetical)

Forecast weekly outpatient appointments from a stable seasonal history.

Mathematical foundation

Mathematical foundation

forecast / updating rule

\(\ell_t=\alpha y_t+(1-\alpha)\ell_{t-1},\qquad \hat{y}_{t+1\mid t}=\ell_t\)
View LaTeX source
\ell_t=\alpha y_t+(1-\alpha)\ell_{t-1},\qquad \hat{y}_{t+1\mid t}=\ell_t

Symbols

ℓ_t: smoothed level; α between 0 and 1: smoothing parameter; y_t: observed value.

Explanation

Simple exponential smoothing repeatedly updates the estimated level using recent errors.

Important scope limitation

This is ETS(A,N,N) / simple exponential smoothing only; ETS also supports trend, seasonality and different error forms.

Assumptions and diagnostics

Assumptions and conditions

Time series has a form of level, trend or seasonality supported by chosen ETS components and a suitable error specification.

Diagnostics to perform

Review decomposition/seasonal plots, residual ACF, forecast errors, component plausibility and rolling-origin validation.

Consequences of violations

Wrong seasonal/trend components or autocorrelated residuals degrade forecast accuracy and interval calibration.

Diagnostic caveats

Multiplicative ETS specifications usually require positive values; an apparent trend is not guaranteed to persist in forecasting.

Understanding the results

Primary outputs

Estimated level/trend/seasonal state parameters, forecasts and prediction intervals.

Inference and tests

ETS is primarily a forecasting framework; component significance tests are not generally the focus.

Effect sizes and intervals

Report point forecasts and prediction intervals, with horizon and outcome units.

Model fit and performance

Compare rolling-origin MAE/RMSE/MASE, residual whiteness and AICc among suitable ETS structures.

Interpreting results

The modeled level, trend and seasonality extrapolate historical patterns subject to forecast uncertainty.

Common mistakes

Good training fit does not ensure future performance after an intervention or structural shift.

Example report wording (placeholder values)

ETS([error],[trend],[season]) forecast at [h] = [value] (95% PI [limits]); validation MASE = [value].

Simulated data

R example

set.seed(2026)
n<-180
t<-seq_len(n)
y<-20 + .04*t + 2*sin(2*pi*t/12) + as.numeric(arima.sim(list(ar=.5),n=n,sd=1.5))
d<-data.frame(t,y)

series<-ts(d$y,frequency=12)
fit<-HoltWinters(series,seasonal="additive")
print(predict(fit,n.ahead=6))

Python tutorial

Learning goal

Model level, trend and additive seasonality using exponential smoothing.

Simulated data

180 consecutive monthly observations with trend, seasonality and serial dependence.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng=np.random.default_rng(2026)
n=180
t=np.arange(1,n+1)
eps=rng.normal(0,1.5,n)
noise=np.zeros(n)
for j in range(1,n): noise[j]=.5*noise[j-1]+eps[j]
y=20+.04*t+2*np.sin(2*np.pi*t/12)+noise
d=pd.DataFrame({"t":t,"y":y})

from statsmodels.tsa.holtwinters import ExponentialSmoothing
fit=ExponentialSmoothing(d.y,trend="add",seasonal="add",seasonal_periods=12).fit()
print(fit.forecast(6))
