Mediation Analysis

Statistical method reference guide

Overview and appropriate use

Purpose

Mediation analysis separates a hypothesized total effect into pathways operating through a proposed intermediate variable and other pathways.

Example research questions

How much of an intervention effect on fitness may operate through increased activity?

Design requirements

Exposure, mediator, and outcome with suitable temporal ordering and a credible identification strategy for causal mediation claims.

Strengths

Makes mechanisms explicit and can estimate direct and indirect effects under specified models.

Limitations

Unmeasured mediator-outcome confounding, treatment-induced confounding, and model misspecification can invalidate causal interpretations.

When not to use it

Do not infer that a significant indirect association proves a biological or behavioral mechanism.

Illustrative research scenario (hypothetical)

Examine whether improved sleep mediates a treatment's effect on fatigue under a clearly stated causal framework.

Mathematical foundation

Mathematical foundation

mediation decomposition

\(M_i=a_0+aX_i+\varepsilon_{Mi},\quad Y_i=b_0+c^\prime X_i+bM_i+\varepsilon_{Yi},\quad \mathrm{Indirect}=ab\)
View LaTeX source
M_i=a_0+aX_i+\varepsilon_{Mi},\quad Y_i=b_0+c^\prime X_i+bM_i+\varepsilon_{Yi},\quad \mathrm{Indirect}=ab

Symbols

X: exposure; M: mediator; Y: outcome; a,b: path coefficients; c-prime: direct-effect coefficient.

Explanation

In a simple linear mediation model the product ab represents the modeled indirect pathway.

Important scope limitation

A causal indirect effect requires strong sequential ignorability and timing assumptions; effects need not decompose so simply for nonlinear models.

Assumptions and diagnostics

Assumptions and conditions

Exposure precedes mediator, which precedes outcome. Causal mediation requires no unmeasured exposure-outcome, mediator-outcome or exposure-mediator confounding under the chosen estimand; no relevant post-exposure mediator-outcome confounder under conventional identification.

Diagnostics to perform

Audit variable timing and causal diagram, pre-exposure covariates, mediator-outcome confounding candidates, positivity, and run sensitivity analyses for unmeasured confounding.

Consequences of violations

Violations of sequential exchangeability can make indirect-effect estimates biased or uninterpretable as causal mediation.

Diagnostic caveats

No diagnostic test proves mediator-outcome exchangeability; an observed association through a mediator is not automatically a causal indirect effect.

Understanding the results

Primary outputs

Total, direct and indirect effect estimates, mediator path estimates and their uncertainty.

Inference and tests

Bootstrap or appropriate analytical intervals test indirect effects under the model and identification assumptions.

Effect sizes and intervals

Report indirect effect a×b and confidence interval; proportion mediated is often unstable and needs careful definition.

Model fit and performance

Inspect sensitivity to mediator–outcome confounding and functional form; global fit indices depend on mediation model chosen.

Interpreting results

An indirect-effect estimate describes a modeled pathway contribution under strong causal assumptions when interpreted causally.

Common mistakes

Statistical mediation alone does not demonstrate a causal mechanism, even in a randomized treatment trial.

Example report wording (placeholder values)

Indirect effect = [estimate] (95% bootstrap CI [limits]); direct effect = [estimate]; assumptions = [summary].

R tutorial

Learning goal

Estimate a proposed indirect pathway through mediator m.

Simulated data

Observational treatment assignment dependent on measured confounder x; continuous outcome.

Packages

mediation

R example

set.seed(2026)
n<-450
x<-rnorm(n)
p_treat<-plogis(-.2+.9*x)
treated<-rbinom(n,1,p_treat)
y<-4+1.6*treated+1.4*x+rnorm(n,sd=1.2)
d<-data.frame(y,x,treated)

set.seed(2027)
d$m <- .8*d$treated + .5*d$x + rnorm(nrow(d))
d$y <- .5*d$treated + .6*d$m + .5*d$x + rnorm(nrow(d))
mfit <- lm(m~treated+x,data=d)
yfit <- lm(y~treated+m+x,data=d)
fit <- mediation::mediate(mfit,yfit,treat="treated",mediator="m",sims=200,
                          boot=FALSE)
print(summary(fit))

Limitations and checks

Mediation identification needs strong treatment–mediator and mediator–outcome confounding assumptions; Python uses a simpler product estimator.

Python tutorial

Learning goal

Estimate a proposed indirect pathway through mediator m.

Simulated data

Observational treatment assignment dependent on measured confounder x; continuous outcome.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng=np.random.default_rng(2026)
n=450
x=rng.normal(size=n)
p_treat=1/(1+np.exp(-(-.2+.9*x)))
treated=rng.binomial(1,p_treat)
y=4+1.6*treated+1.4*x+rng.normal(0,1.2,n)
d=pd.DataFrame({"y":y,"x":x,"treated":treated})

# Simple bootstrap of product-of-coefficients; not identical to mediation::mediate
import statsmodels.formula.api as smf
d["m"] = .8*d.treated+.5*d.x+rng.normal(size=len(d))
d["y"] = .5*d.treated+.6*d.m+.5*d.x+rng.normal(size=len(d))
a=smf.ols("m ~ treated + x",data=d).fit().params["treated"]
b=smf.ols("y ~ treated + m + x",data=d).fit().params["m"]
boot=[]
for k in range(200):
    sample=d.iloc[rng.integers(0,len(d),len(d))]
    aa=smf.ols("m ~ treated + x",data=sample).fit().params["treated"]
    bb=smf.ols("y ~ treated + m + x",data=sample).fit().params["m"]
    boot.append(aa*bb)
print("Indirect product:",a*b,"bootstrap interval:",np.percentile(boot,[2.5,97.5]))
