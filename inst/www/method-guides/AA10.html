Wilcoxon Signed-Rank Test

Statistical method reference guide

Overview and appropriate use

Purpose

The Wilcoxon signed-rank test evaluates whether paired differences are systematically centered away from zero using their signs and ranks.

Example research questions

Do matched patients tend to report higher symptom scores after treatment?

Design requirements

Matched or repeated pairs with ordinal or numeric differences; symmetry of the difference distribution supports the usual location interpretation.

Strengths

Nonparametric paired comparison less dependent on normal differences than a paired t-test.

Limitations

Ties, zeros, and asymmetric differences complicate interpretation; it does not model trajectories over multiple visits.

When not to use it

Do not use for independent groups or automatically interpret the result as a median change under arbitrary asymmetry.

Illustrative research scenario (hypothetical)

Compare paired mobility scores before and after rehabilitation.

Mathematical foundation

Mathematical foundation

rank test statistic

\(W^+=\sum_{i:d_i>0}\operatorname{rank}(|d_i|)\)
View LaTeX source
W^+=\sum_{i:d_i>0}\operatorname{rank}(|d_i|)

Symbols

d_i: nonzero paired difference; rank(|d_i|): rank of its absolute magnitude.

Explanation

Tests signed differences using both sign and relative magnitude.

Important scope limitation

The familiar location interpretation requires a suitably symmetric difference distribution; zeros and ties need handling.

Assumptions and diagnostics

Assumptions and conditions

Valid matched pairs with independent differences across participants. For the usual symmetric location-shift interpretation, the paired-difference distribution is approximately symmetric.

Diagnostics to perform

Plot paired differences with histogram and boxplot; inspect zero differences, ties, and symmetry around the center; verify pair matching.

Consequences of violations

Asymmetric differences undermine a simple median-shift interpretation; incorrect pairing or interdependent pairs invalidates standard inference.

Diagnostic caveats

The Wilcoxon signed-rank test is not the same as a sign test, and does not require normal paired differences.

Understanding the results

Primary outputs

Wilcoxon signed-rank statistic, paired-difference ranks and number of nonzero pairs.

Inference and tests

Tests symmetry-centered paired differences around zero under its standard location interpretation; p-values may be exact or approximate.

Effect sizes and intervals

Report Hodges–Lehmann pseudomedian shift and interval where appropriate, plus number of zero and nonzero differences.

Model fit and performance

Inspect paired differences and symmetry; no model fit metric.

Interpreting results

Evidence of a positive signed-rank shift supports a systematically positive paired change.

Common mistakes

It is not simply a distribution-free paired t-test and is not always a test of the median difference without symmetry.

Example report wording (placeholder values)

Wilcoxon signed-rank V = [V] (nonzero pairs = [n], p = [p]); estimated shift = [shift].

R tutorial

Learning goal

Test whether paired changes are centered at zero in a signed-rank framework.

Simulated data

90 participants with correlated baseline and follow-up blood-pressure readings.

Packages

stats

R example

set.seed(2026)
n <- 90
before <- rnorm(n, mean = 125, sd = 13)
after <- before - 5 + rnorm(n, sd = 7)
d <- data.frame(id = seq_len(n), before, after)

print(wilcox.test(d$after,d$before,paired=TRUE,exact=FALSE))

Output to inspect

Signed-rank statistic and p-value.

Limitations and checks

Requires appropriate symmetry for a median-change interpretation.

Python tutorial

Learning goal

Test whether paired changes are centered at zero in a signed-rank framework.

Simulated data

90 participants with correlated baseline and follow-up blood-pressure readings.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
before = rng.normal(125, 13, n)
after = before - 5 + rng.normal(0, 7, n)
d = pd.DataFrame({"id": np.arange(n), "before": before, "after": after})

from scipy import stats
print(stats.wilcoxon(d.after-d.before,alternative="two-sided"))
