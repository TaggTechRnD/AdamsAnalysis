Exploratory Factor Analysis (EFA)

Statistical method reference guide

Overview and appropriate use

Purpose

Exploratory factor analysis models shared covariance among questionnaire items using a smaller number of hypothesized latent factors.

Example research questions

What underlying dimensions appear to organize answers to a new wellbeing survey?

Design requirements

Multiple appropriately measured items, adequate sample information, a defensible factor model, and a suitable estimator for item scales.

Strengths

Offers a principled exploratory framework for detecting common latent structure.

Limitations

Factor count and rotation can be ambiguous; results are not confirmation of a predefined measurement model.

When not to use it

Do not use exploratory factors alone as proof that a scale is valid across populations.

Illustrative research scenario (hypothetical)

Explore whether twenty wellbeing items reflect stress, social support, and mood dimensions.

Mathematical foundation

Mathematical foundation

latent-variable model

\(\boldsymbol{x}=\Lambda\boldsymbol{f}+\boldsymbol{\epsilon},\qquad \Sigma=\Lambda\Phi\Lambda^\top+\Psi\)
View LaTeX source
\boldsymbol{x}=\Lambda\boldsymbol{f}+\boldsymbol{\epsilon},\qquad \Sigma=\Lambda\Phi\Lambda^\top+\Psi

Symbols

Λ: factor loadings; f: latent factors; Φ: factor covariance; Ψ: unique variance matrix.

Explanation

Represents observed covariation through a smaller set of common latent factors.

Important scope limitation

Factor number and rotation affect interpretation; an exploratory factor solution is not causal proof.

Assumptions and diagnostics

Assumptions and conditions

Indicators share enough common covariance for a defensible factor model; factor count and rotation are justified and the model is identifiable.

Diagnostics to perform

Inspect correlation or polychoric matrix as appropriate, KMO, Bartlett test as context, eigenvalues and parallel analysis, communalities, loadings and residual correlations.

Consequences of violations

Weak factorability, too many factors or inadequate sample information produce unstable, poorly interpretable loadings.

Diagnostic caveats

Bartlett significance alone does not establish factorability; EFA explores structure and is not confirmatory evidence by itself.

Understanding the results

Primary outputs

Factor loadings, communalities, factor correlations and chosen factor count.

Inference and tests

Exploratory factor extraction can include model-fit tests for some estimators; inference is conditional on extraction/rotation.

Effect sizes and intervals

Loading magnitudes indicate association with common factors; bootstrap intervals may assess stability.

Model fit and performance

Parallel analysis, residual correlations, RMSEA/TLI for suitable common-factor fitting methods, and interpretability.

Interpreting results

A loading of 0.7 indicates a relatively strong modeled relationship between item and factor, not a 70% effect.

Common mistakes

An interpretable exploratory solution is not independent confirmation of construct validity.

Example report wording (placeholder values)

[k]-factor EFA using [estimator/rotation] yielded salient loadings [range]; communalities [range]; fit [metric].

R tutorial

Learning goal

Explore a two-factor measurement structure.

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

stats

R example

set.seed(2026)
n <- 240
f1 <- rnorm(n); f2 <- 0.3*f1 + rnorm(n)
d <- data.frame(
  a1=0.9*f1+rnorm(n,sd=.5), a2=0.8*f1+rnorm(n,sd=.6),
  a3=0.7*f1+rnorm(n,sd=.6), b1=0.9*f2+rnorm(n,sd=.5),
  b2=0.8*f2+rnorm(n,sd=.6), b3=0.7*f2+rnorm(n,sd=.6))

fit<-factanal(d,factors=2,rotation="varimax")
print(fit)

Output to inspect

Rotated item loadings and uniquenesses.

Limitations and checks

Factor count and rotation are substantive choices; factor labels are interpretive.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 240
f1 = rng.normal(size=n); f2 = .3*f1 + rng.normal(size=n)
d = pd.DataFrame({
 "a1":.9*f1+rng.normal(0,.5,n), "a2":.8*f1+rng.normal(0,.6,n),
 "a3":.7*f1+rng.normal(0,.6,n), "b1":.9*f2+rng.normal(0,.5,n),
 "b2":.8*f2+rng.normal(0,.6,n), "b3":.7*f2+rng.normal(0,.6,n)})

# Install optional dependency beforehand: pip install factor_analyzer
from factor_analyzer import FactorAnalyzer
fit=FactorAnalyzer(n_factors=2,rotation="varimax",method="ml").fit(d)
print("Loadings:\n",fit.loadings_)
print("Uniquenesses:",fit.get_uniquenesses())
