MANOVA

Statistical method reference guide

Overview and appropriate use

Purpose

Multivariate analysis of variance tests group effects jointly across several related continuous outcomes.

Example research questions

Does a treatment alter the combined profile of blood pressure and cholesterol outcomes?

Design requirements

Multiple continuous outcomes measured on each unit, group factors, appropriate independent units, and estimable covariance structure.

Strengths

Jointly tests multivariate outcome differences while accounting for correlations among outcomes.

Limitations

Interpretation of a significant omnibus result requires follow-up; results can be sensitive to covariance structure and sample size.

When not to use it

Do not use when outcomes are unrelated measurements from different participants or infer which outcome changed from the omnibus test alone.

Illustrative research scenario (hypothetical)

Compare the joint changes in strength, endurance, and balance across training groups.

Mathematical foundation

Mathematical foundation

multivariate test statistic

\(\Lambda_{\mathrm{Wilks}}=\frac{|E|}{|E+H|}\)
View LaTeX source
\Lambda_{\mathrm{Wilks}}=\frac{|E|}{|E+H|}

Symbols

E: within/error sum-of-products matrix; H: hypothesis sum-of-products matrix; |·|: determinant.

Explanation

Wilks’ lambda assesses multivariate mean separation across multiple continuous outcomes.

Important scope limitation

One of several MANOVA statistics; sample size, covariance assumptions and multivariate outliers matter.

Assumptions and diagnostics

Assumptions and conditions

Two or more continuous outcomes, independent sampling units, reasonably well-specified multivariate error structure, and group covariance behavior compatible with the chosen test.

Diagnostics to perform

Check multivariate outliers, residual correlation and Q-Q diagnostics, cell counts, covariance matrices (Box M cautiously), and singularity among outcomes.

Consequences of violations

Sparse cells, nonnormal multivariate residuals or strongly differing covariance matrices can distort classical multivariate F approximations.

Diagnostic caveats

Pillai trace is often more robust than some alternatives but does not remove all design or covariance problems.

Understanding the results

Primary outputs

Multivariate test statistics (e.g., Pillai trace), approximate F and degrees of freedom, outcomes and group contrasts.

Inference and tests

Overall MANOVA tests whether the multivariate mean vector differs; follow-up tests require multiplicity and correlation awareness.

Effect sizes and intervals

Report multivariate effect index alongside each outcome’s estimated mean contrast with interval.

Model fit and performance

Inspect multivariate residual structure, group covariance and influential observations; report chosen multivariate statistic.

Interpreting results

Significant Pillai trace suggests the groups differ somewhere in the joint set of continuous outcomes.

Common mistakes

An omnibus result does not establish that every outcome differs; univariate tests alone discard multivariate context.

Example report wording (placeholder values)

MANOVA Pillai trace = [V], F([df1], [df2]) = [F], p = [p]; outcomes = [list].

R tutorial

Learning goal

Test whether independent groups differ on multiple continuous outcomes jointly.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

set.seed(2027)
d$y2<-5+.7*d$x+0.6*(d$group=="Treatment")+rnorm(nrow(d))
fit<-manova(cbind(y,y2)~group,data=d)
print(summary(fit,test="Pillai"))

Output to inspect

Pillai trace or other multivariate statistic.

Limitations and checks

Check multivariate outliers and dependence; multivariate significance is not specific to one outcome.

Simulated data

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.api as sm
from statsmodels.multivariate.manova import MANOVA
rng2=np.random.default_rng(2027)
d["y2"]=5+.7*d.x+.6*(d.group=="Treatment")+rng2.normal(size=len(d))
fit=MANOVA.from_formula("y + y2 ~ C(group)",data=d)
print(fit.mv_test())
