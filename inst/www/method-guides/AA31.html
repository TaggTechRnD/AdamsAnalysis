Cross-Tabulation

Statistical method reference guide

Overview and appropriate use

Purpose

Cross-tabulation displays counts or percentages for combinations of categorical variables to reveal their joint distribution.

Example research questions

How does smoking status vary by age group?

Design requirements

Correct categorical coding, a defined population, and clear row or column denominators.

Strengths

Transparent descriptive overview that can reveal sparsity before formal analysis.

Limitations

Does not quantify sampling uncertainty or establish an association on its own.

When not to use it

Do not infer statistical significance from percentage differences without a suitable inferential method.

Illustrative research scenario (hypothetical)

Display vaccination status by clinic in a table of counts and row percentages.

Mathematical foundation

Mathematical foundation

descriptive statistic

\(n_{jk}=\sum_{i=1}^{n}\mathbf{1}(X_i=j,Y_i=k)\)
View LaTeX source
n_{jk}=\sum_{i=1}^{n}\mathbf{1}(X_i=j,Y_i=k)

Symbols

n_jk: joint count in category pair (j,k); 1(·): indicator.

Explanation

Cross-tabulation counts observations across combinations of two categorical variables.

Important scope limitation

Cell percentages can be row-, column-, or table-based; report the denominator.

Assumptions and diagnostics

Assumptions and conditions

Variables have coherent categories and mutually interpretable row/column denominators; records are accurate and appropriately weighted when relevant.

Diagnostics to perform

Inspect contingency-table totals, zeros, duplicate records, category definitions, missingness and row/column/overall percentages.

Consequences of violations

Miscoding and inconsistent denominators lead to misleading summaries, especially where sample sizes differ across groups.

Diagnostic caveats

Cross-tabulation is descriptive; significance or causal interpretation requires a separate inferential analysis and design.

Understanding the results

Primary outputs

Joint category counts and row, column or total percentages with clearly stated denominators.

Inference and tests

Descriptive only; association tests such as chi-square or Fisher exact must be specified separately.

Effect sizes and intervals

Report differences in percentages, risk ratios or odds ratios with intervals when scientific comparisons warrant them.

Model fit and performance

Check sparse cells, missing categories and denominators; model fit is not applicable.

Interpreting results

A row percentage answers what fraction of one row category is in a given column category.

Common mistakes

Row and column percentages answer different questions; a cross-tabulation alone does not establish statistical association.

Example report wording (placeholder values)

Among [row category], [n]/[denominator] ([percent]%) had [column category].

R tutorial

Learning goal

Produce cross-tabulations and within-group proportions.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

ct<-table(Treatment=d$treatment,Outcome=d$y)
print(addmargins(ct))
print(prop.table(ct,margin=1))

Output to inspect

Cell counts, margins, and denominator-aware percentages.

Limitations and checks

A crosstab is descriptive; no causal inference is justified.

Python tutorial

Learning goal

Produce cross-tabulations and within-group proportions.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

ct=pd.crosstab(d.treatment,d.y,margins=True)
print(ct)
print(pd.crosstab(d.treatment,d.y,normalize="index"))
