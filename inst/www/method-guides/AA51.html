Log-Rank Test

Statistical method reference guide

Overview and appropriate use

Purpose

Log-rank test compares observed and expected events across survival groups over follow-up.

Example research questions

Do event-free survival curves differ between two randomized treatment groups?

Design requirements

Time-to-event data from independent groups, comparable event definitions, and suitable censoring; greatest efficiency commonly occurs under proportional hazards.

Strengths

Provides a simple global comparison of survival experience across groups.

Limitations

Does not estimate a covariate-adjusted effect or identify when curves differ; crossing hazards reduce interpretability.

When not to use it

Do not use to claim a constant hazard ratio when hazards are clearly nonproportional.

Illustrative research scenario (hypothetical)

Compare time to readmission across two treatment groups.

Mathematical foundation

Mathematical foundation

survival test statistic

\(Z=\frac{\sum_j(O_j-E_j)}{\sqrt{\sum_jV_j}}\)
View LaTeX source
Z=\frac{\sum_j(O_j-E_j)}{\sqrt{\sum_jV_j}}

Symbols

O_j,E_j: observed and expected group events at event time j; V_j: corresponding variance contribution.

Explanation

The two-group log-rank test compares observed versus expected events across follow-up.

Important scope limitation

Shown as a schematic two-group statistic; crossing hazards can reduce test power and complicate interpretation.

Assumptions and diagnostics

Assumptions and conditions

Independent groups have comparable event and censoring definitions; censoring is conditionally noninformative. Ordinary log-rank is most powerful under approximately proportional hazards.

Diagnostics to perform

Inspect Kaplan-Meier curves, numbers at risk, censoring by group and potential crossing curves; check ties and event counts.

Consequences of violations

Informative censoring or incorrect grouping biases inference; crossing hazards can reduce power or obscure time-specific differences.

Diagnostic caveats

Noncrossing/proportional hazards is not required for the log-rank statistic to be computed; it affects the test power and summary interpretation.

Understanding the results

Primary outputs

Log-rank chi-square statistic, degrees of freedom, group survival curves and p-value.

Inference and tests

Tests the null of equal event-time distributions under the risk-set weighting used; interpretation depends on independent censoring.

Effect sizes and intervals

Report survival differences at meaningful times and CIs separately; a log-rank test alone has no HR estimate.

Model fit and performance

Inspect Kaplan–Meier curves, crossings and at-risk numbers; model-fit statistics are not part of the test.

Interpreting results

A significant test indicates evidence of differing event-time experiences between groups.

Common mistakes

A non-significant log-rank test does not prove equal survival and may miss important crossing hazards.

Example report wording (placeholder values)

Log-rank χ²([df]) = [stat], p = [p]; survival at [time] differed by [diff] percentage points.

R tutorial

Learning goal

Compare event-time curves between treatment arms.

Simulated data

Time-to-event outcomes with random right censoring and treatment/risk covariates.

Packages

survival

R example

set.seed(2026)
n <- 250
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
rate <- 0.08*exp(0.5*x - 0.5*treatment)
true_time <- rexp(n, rate=rate)
censor_time <- runif(n, 5, 22)
time <- pmin(true_time, censor_time)
event <- as.integer(true_time <= censor_time)
d <- data.frame(time, event, x, treatment)

print(survival::survdiff(survival::Surv(time,event)~treatment,data=d))

Output to inspect

Log-rank chi-square statistic and p-value.

Limitations and checks

Censoring assumptions and crossing hazards affect interpretation.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 250
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
rate = .08*np.exp(.5*x - .5*treatment)
true_time = rng.exponential(scale=1/rate)
censor_time = rng.uniform(5,22,n)
time = np.minimum(true_time,censor_time)
event = (true_time <= censor_time).astype(int)
d = pd.DataFrame({"time":time,"event":event,"x":x,"treatment":treatment})

# Install optional dependency beforehand: pip install lifelines
from lifelines.statistics import logrank_test
a=d[d.treatment==0];b=d[d.treatment==1]
print(logrank_test(a.time,b.time,event_observed_A=a.event,event_observed_B=b.event).summary)
