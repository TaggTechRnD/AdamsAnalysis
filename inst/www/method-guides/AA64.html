Elastic Net Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Elastic net blends L1 and L2 penalties to regularize regression models and encourage grouped treatment of correlated predictors.

Example research questions

Can a stable prediction model be built from many correlated behavioral measures?

Design requirements

Specified response, suitable model family, standardized predictors where appropriate, and validation of penalty strength and mixing parameter.

Strengths

Balances sparsity and coefficient stability when predictors are highly correlated.

Limitations

Requires tuning and can still select unstable sets when information is weak.

When not to use it

Do not confuse cross-validated predictive usefulness with causal relevance of selected predictors.

Illustrative research scenario (hypothetical)

Predict rehabilitation outcomes using a large correlated set of mobility measures.

Mathematical foundation

Mathematical foundation

penalized optimization

\(\min_{\beta_0,\boldsymbol{\beta}}\sum_i(y_i-\beta_0-\boldsymbol{x}_i^\top\boldsymbol{\beta})^2+\lambda\left(\alpha\sum_j|\beta_j|+\frac{1-\alpha}{2}\sum_j\beta_j^2\right)\)
View LaTeX source
\min_{\beta_0,\boldsymbol{\beta}}\sum_i(y_i-\beta_0-\boldsymbol{x}_i^\top\boldsymbol{\beta})^2+\lambda\left(\alpha\sum_j|\beta_j|+\frac{1-\alpha}{2}\sum_j\beta_j^2\right)

Symbols

λ≥0: penalty strength; α in [0,1]: mix between LASSO (1) and ridge (0).

Explanation

Elastic net combines L1 and L2 shrinkage to handle selection and correlated predictors.

Important scope limitation

Exact penalty scaling differs between software implementations.

Assumptions and diagnostics

Assumptions and conditions

Model family/link is appropriate; predictor scaling and elastic-net mixing/penalty parameters are selected through leak-free validation.

Diagnostics to perform

Check cross-validation for alpha and lambda, standardized predictors, coefficient stability and out-of-sample errors.

Consequences of violations

Poor tuning or inconsistent scaling compromises prediction; unmodeled dependence invalidates ordinary random folds.

Diagnostic caveats

Coefficient selection does not independently establish causality or conventional confidence intervals.

Understanding the results

Primary outputs

Elastic-net coefficients, penalty magnitude λ, mixing parameter α and predictions.

Inference and tests

Ordinary unpenalized coefficient tests are not valid after selection/shrinkage without specialized inference.

Effect sizes and intervals

Report selected coefficient patterns, stability and validated predictive performance.

Model fit and performance

Use nested/appropriate cross-validation to tune α and λ; report held-out loss or calibration.

Interpreting results

Elastic net combines L1 and L2 shrinkage and can retain groups of correlated predictors in some settings.

Common mistakes

A selected predictor is not necessarily a causal driver; coefficient scale depends on standardization and tuning.

Example report wording (placeholder values)

R tutorial

Learning goal

Combine L1 and L2 coefficient penalties.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

glmnet

R example

set.seed(2026)
n <- 300
x1<-rnorm(n); x2<-rnorm(n); x3<-rnorm(n)
y<-3 + 2*x1 - x2 + 0.7*x3 + rnorm(n,sd=1.5)
d<-data.frame(y,x1,x2,x3)
idx<-sample(seq_len(n),round(.7*n))
train<-d[idx,];test<-d[-idx,]

fit<-glmnet::cv.glmnet(as.matrix(train[c("x1","x2","x3")]),train$y,
                       alpha=.5,nfolds=5)
print(coef(fit,s="lambda.min"))

Output to inspect

Selected penalty and coefficient shrinkage.

Limitations and checks

The R glmnet and sklearn penalty parameterizations are not numerically identical.

Python tutorial

Learning goal

Combine L1 and L2 coefficient penalties.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng=np.random.default_rng(2026)
n=300
x1=rng.normal(size=n);x2=rng.normal(size=n);x3=rng.normal(size=n)
y=3+2*x1-x2+.7*x3+rng.normal(0,1.5,n)
d=pd.DataFrame({"y":y,"x1":x1,"x2":x2,"x3":x3})
train,test=train_test_split(d,test_size=.3,random_state=2026)

from sklearn.linear_model import ElasticNetCV
fit=ElasticNetCV(l1_ratio=.5,cv=5,random_state=2026,max_iter=5000).fit(
    train[["x1","x2","x3"]],train.y)
print("Alpha:",fit.alpha_,"coefficients:",fit.coef_)
