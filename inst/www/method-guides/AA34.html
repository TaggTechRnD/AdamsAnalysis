Point-Biserial Correlation

Statistical method reference guide

Overview and appropriate use

Purpose

Point-biserial correlation quantifies the linear association between one truly dichotomous variable and one quantitative variable.

Example research questions

Is exercise-program membership associated with a higher measured fitness score?

Design requirements

One binary grouping variable and one numeric variable, with independent observations for conventional inference.

Strengths

Gives a standardized association equivalent to the Pearson correlation with a binary indicator.

Limitations

Sensitive to group proportions and extreme numeric observations; association does not establish treatment efficacy.

When not to use it

Do not use with multiple nominal categories without appropriate recoding or interpret it as a causal treatment effect.

Illustrative research scenario (hypothetical)

Relate binary smoking status to continuous lung-function measurements.

Mathematical foundation

Mathematical foundation

association statistic

\(r_{pb}=\operatorname{cor}(X_{0/1},Y)\)
View LaTeX source
r_{pb}=\operatorname{cor}(X_{0/1},Y)

Symbols

X_0/1: binary group indicator coded 0 or 1; Y: continuous measurement.

Explanation

Point-biserial correlation is Pearson correlation when one variable is binary.

Important scope limitation

Coding reverses the sign; a binary predictor does not make the observed association causal.

Assumptions and diagnostics

Assumptions and conditions

One variable is genuinely binary and the other continuous; independent sampling units and consistent binary coding.

Diagnostics to perform

Check group coding and sizes, within-group distributions, outliers and independence; compare with the equivalent two-group mean comparison.

Consequences of violations

Severe outliers or coding errors distort correlation; dependent measures invalidate standard inference.

Diagnostic caveats

Point-biserial correlation measures association with a binary indicator, not a causal treatment effect by itself.

Understanding the results

Primary outputs

Point-biserial correlation r_pb, sample size and group-wise summary of continuous variable.

Inference and tests

Equivalent standard inference to a two-group Pearson correlation/t test under the relevant assumptions.

Effect sizes and intervals

r_pb summarizes standardized association between binary indicator and continuous variable; report CI and underlying group difference.

Model fit and performance

Examine group sizes, distribution and coding; no additional model fit metric.

Interpreting results

Positive r_pb means the category coded 1 has a higher average continuous outcome than category 0.

Common mistakes

Direction flips if binary coding is reversed; the correlation is not causal.

Example report wording (placeholder values)

Point-biserial r = [r] (95% CI [lower], [upper], n = [n]); binary coding: [0/1 labels].

R tutorial

Learning goal

Quantify association of a binary group indicator and a numerical outcome (here binary for illustration).

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

indicator<-as.integer(d$group=="Treatment")
print(cor.test(indicator,d$y,method="pearson"))

Output to inspect

Point-biserial correlation magnitude and p-value.

Limitations and checks

Continuous outcome and binary group indicator; interpretation is associative, not causal.

Python tutorial

Learning goal

Quantify association of a binary group indicator and a numerical outcome (here binary for illustration).

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
indicator=(d.group=="Treatment").astype(int)
print(stats.pointbiserialr(indicator,d.y))
