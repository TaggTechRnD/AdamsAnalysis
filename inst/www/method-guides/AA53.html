Path Analysis

Statistical method reference guide

Overview and appropriate use

Purpose

Path analysis represents hypothesized directional relationships among measured variables using a system of regression equations.

Example research questions

Are activity, sleep, and health associated along a prespecified network of direct and indirect paths?

Design requirements

Observed variables, identified path structure, credible temporal and conceptual ordering, and suitable distribution or estimation choices.

Strengths

Evaluates several linked associations simultaneously and makes indirect pathways explicit.

Limitations

Model fit does not establish the causal direction of arrows; omitted pathways and measurement error may bias estimates.

When not to use it

Do not draw causal conclusions simply because the proposed arrows fit the covariance data.

Illustrative research scenario (hypothetical)

Assess hypothesized links from occupational stress to sleep duration and subsequent fatigue.

Mathematical foundation

Mathematical foundation

structural regression system

\(M_i=a_0+aX_i+\varepsilon_{Mi},\qquad Y_i=c_0+cX_i+bM_i+\varepsilon_{Yi}\)
View LaTeX source
M_i=a_0+aX_i+\varepsilon_{Mi},\qquad Y_i=c_0+cX_i+bM_i+\varepsilon_{Yi}

Symbols

X: explanatory variable; M: intermediate variable; Y: dependent variable; a,b,c: path coefficients.

Explanation

A path model represents several directed regression relations in one system.

Important scope limitation

Specified arrows express causal hypotheses but fitted path coefficients alone do not prove causation.

Assumptions and diagnostics

Assumptions and conditions

A path diagram and direction of associations are theoretically justified and identifiable; exogenous confounding is addressed when paths are interpreted causally.

Diagnostics to perform

Review identification, convergence, residual covariances, model fit, path stability, and sensitivity to plausible omitted confounders.

Consequences of violations

Omitted causes or incorrect directionality can yield biased causal paths even if global fit looks acceptable.

Diagnostic caveats

Statistical fit cannot establish causal direction; cross-sectional path models are especially vulnerable to equivalent alternative models.

Understanding the results

Primary outputs

Estimated standardized/unstandardized path coefficients, variances and, where overidentified, global model fit.

Inference and tests

Path coefficients have model-based standard errors, intervals and tests; indirect effects may need resampling.

Effect sizes and intervals

Report direct/indirect path estimates with confidence intervals, specifying scale and adjustment.

Model fit and performance

χ², CFI/TLI, RMSEA and SRMR are meaningful for identified overidentified models; saturated models do not test global fit.

Interpreting results

A path coefficient quantifies a modeled conditional association along the specified directed edge.

Common mistakes

Arrows do not create causal identification; an excellent fit does not prove the proposed direction of causation.

Example report wording (placeholder values)

Path X→Y = [beta] (95% CI [limits]); global fit = [indices or saturated model].

R tutorial

Learning goal

Estimate prespecified observed-variable directional regression paths.

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

lavaan

R example

set.seed(2026)
n <- 240
f1 <- rnorm(n); f2 <- 0.3*f1 + rnorm(n)
d <- data.frame(
  a1=0.9*f1+rnorm(n,sd=.5), a2=0.8*f1+rnorm(n,sd=.6),
  a3=0.7*f1+rnorm(n,sd=.6), b1=0.9*f2+rnorm(n,sd=.5),
  b2=0.8*f2+rnorm(n,sd=.6), b3=0.7*f2+rnorm(n,sd=.6))

model <- 'a2 ~ a1
b1 ~ a1 + a2'
fit <- lavaan::sem(model,data=d)
print(lavaan::parameterEstimates(fit,standardized=TRUE))

Output to inspect

Direct path coefficients, uncertainty and fit.

Limitations and checks

Arrows express modeled hypotheses, not proof of causal direction.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 240
f1 = rng.normal(size=n); f2 = .3*f1 + rng.normal(size=n)
d = pd.DataFrame({
 "a1":.9*f1+rng.normal(0,.5,n), "a2":.8*f1+rng.normal(0,.6,n),
 "a3":.7*f1+rng.normal(0,.6,n), "b1":.9*f2+rng.normal(0,.5,n),
 "b2":.8*f2+rng.normal(0,.6,n), "b3":.7*f2+rng.normal(0,.6,n)})

# Install optional dependency beforehand: pip install semopy
from semopy import Model
model="a2 ~ a1\nb1 ~ a1 + a2"
fit=Model(model)
fit.fit(d)
print(fit.inspect())
