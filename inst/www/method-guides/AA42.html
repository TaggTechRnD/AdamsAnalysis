Multinomial Logistic Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Multinomial logistic regression models the relative probabilities of outcomes with three or more unordered categories.

Example research questions

Which patient characteristics are associated with choosing one of several treatment options?

Design requirements

Nominal multicategory outcome, suitable predictors, an identified reference category, and sufficient observations in each outcome class.

Strengths

Models multiple competing nominal outcomes in one framework.

Limitations

Coefficients depend on the reference class; sparse categories and the independence-of-irrelevant-alternatives assumption may be concerns.

When not to use it

Do not use when categories have a substantive ordering that an ordinal model should exploit.

Illustrative research scenario (hypothetical)

Model whether patients select in-person, virtual, or no follow-up care.

Mathematical foundation

Mathematical foundation

generalized linear model

\(\log\!\left(\frac{P(Y_i=k)}{P(Y_i=K)}\right)=\alpha_k+\boldsymbol{x}_i^\top\boldsymbol{\beta}_k,\quad k<K\)
View LaTeX source
\log\!\left(\frac{P(Y_i=k)}{P(Y_i=K)}\right)=\alpha_k+\boldsymbol{x}_i^\top\boldsymbol{\beta}_k,\quad k<K

Symbols

K: reference outcome category; k: another category; α_k,β_k: category-specific coefficients.

Explanation

Models nominal outcomes by comparing each category’s log-odds to a reference category.

Important scope limitation

This baseline-category specification is for unordered outcomes; estimates depend on the reference group.

Assumptions and diagnostics

Assumptions and conditions

Outcome has at least three nominal categories with correctly defined reference class; class frequencies and predictors support identifiable coefficients.

Diagnostics to perform

Inspect category frequencies, separation and sparse predictor-category cells, convergence, calibration, and multinomial residual or predictive checks.

Consequences of violations

Sparse classes or separation make estimates unstable; class misclassification and omitted structure impair fit.

Diagnostic caveats

Independence-of-irrelevant-alternatives assumptions arise in certain multinomial choice applications; suitability depends on the interpretation and data structure.

Understanding the results

Primary outputs

Category-specific log-odds coefficients and predicted probabilities relative to a chosen outcome reference category.

Inference and tests

Wald or likelihood-ratio tests and confidence intervals apply to coefficients or whole predictors.

Effect sizes and intervals

Report relative risk ratios (exponentiated multinomial logit coefficients) with intervals and/or category probability contrasts.

Model fit and performance

Validate multiclass log loss, calibration and discrimination; pseudo-R² does not equal ordinary variance explained.

Interpreting results

A relative risk ratio above 1 favors one outcome category over the reference category as X increases.

Common mistakes

Relative risk ratio in multinomial logit is not an epidemiologic risk ratio; results depend on outcome reference category.

Example report wording (placeholder values)

For category [k] vs [reference], RRR([X]) = [RRR] (95% CI [limits]); predicted P(category [k]) = [p].

R tutorial

Learning goal

Model an unordered outcome with three categories.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

nnet

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

set.seed(2027)
score<-0.8*d$x-0.4*d$treatment+rnorm(nrow(d))
d$category<-factor(cut(score,breaks=c(-Inf,-.5,.5,Inf),labels=c("Low","Mid","High")))
fit<-nnet::multinom(category~x+treatment,data=d,trace=FALSE)
print(summary(fit))

Output to inspect

Category-specific log-odds relative to reference class.

Limitations and checks

This simulated construction has ordered categories; use the multinomial estimator as if labels were nominal.

Python tutorial

Learning goal

Model an unordered outcome with three categories.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

import statsmodels.api as sm
score=.8*d.x.to_numpy()-.4*d.treatment.to_numpy()+rng.normal(size=len(d))
d["category"]=np.digitize(score,[-.5,.5])
X=sm.add_constant(d[["x","treatment"]])
fit=sm.MNLogit(d.category,X).fit(disp=False)
print(fit.summary())
