Kendall's Tau

Statistical method reference guide

Overview and appropriate use

Purpose

Kendall's tau describes ordinal association using the balance of concordant and discordant observation pairs.

Example research questions

Do higher clinician-rated severity ranks align with higher patient-rated severity ranks?

Design requirements

Paired ordinal or numeric data and a suitable treatment of tied observations.

Strengths

Interpretable rank-association measure, often useful when many ratings are ordinal.

Limitations

Does not provide an effect in original units and may be limited when ties dominate.

When not to use it

Do not treat it as a test of linearity or as evidence that one ranking causes another.

Illustrative research scenario (hypothetical)

Compare agreement in ordering between two clinical severity scales.

Mathematical foundation

Mathematical foundation

association statistic

\(\tau_b=\frac{C-D}{\sqrt{(C+D+T_x)(C+D+T_y)}}\)
View LaTeX source
\tau_b=\frac{C-D}{\sqrt{(C+D+T_x)(C+D+T_y)}}

Symbols

C,D: concordant/discordant observation pairs; T_x,T_y: pairs tied only on one variable.

Explanation

Kendall’s tau-b measures ordinal association based on concordance versus discordance, adjusting for ties.

Important scope limitation

Exact definition of ties matters; the statistic is not a causal effect.

Assumptions and diagnostics

Assumptions and conditions

Paired variables have a meaningful order; units are independent for classical inference. Ties and concordance definition should match the tau variant.

Diagnostics to perform

Inspect scatterplot and ranking ties; confirm whether tau-b or another variant is used, and whether repeated subjects require clustered inference.

Consequences of violations

Ignoring ties changes magnitude and variance; dependence leads to incorrect p-values.

Diagnostic caveats

Kendall tau summarizes ordinal concordance, not linear slope or causation.

Understanding the results

Primary outputs

Kendall tau (tau-b when ties occur), sample size, concordant/discordant pair information.

Inference and tests

Test for no rank association provides p-value with tie-aware approximation or exact calculation where appropriate.

Effect sizes and intervals

Tau measures imbalance of concordance versus discordance; appropriate confidence intervals may be constructed.

Model fit and performance

Inspect ordinal coding, ties and monotonic trend; no model fit statistic.

Interpreting results

Positive tau means concordant ordering of pairs is more common than discordant ordering.

Common mistakes

Tau is not a slope, an explained-variance percentage, or proof of causation.

Example report wording (placeholder values)

Kendall τ-b = [tau] (95% CI [lower], [upper]; p = [p]; n = [n]).

R tutorial

Learning goal

Estimate ordinal concordance.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

print(cor.test(d$x,d$y,method="kendall",exact=FALSE))

Output to inspect

Kendall tau and p-value.

Limitations and checks

Association is noncausal and may reflect confounding.

Python tutorial

Learning goal

Estimate ordinal concordance.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
print(stats.kendalltau(d.x,d.y))
