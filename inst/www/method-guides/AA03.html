Frequencies and Proportions

Statistical method reference guide

Overview and appropriate use

Purpose

Frequencies and proportions summarize how often each category occurs, either as a count or as a fraction of a defined denominator.

Example research questions

What percentage of respondents report current smoking?

Design requirements

Mutually understandable category definitions and an appropriate denominator; account for missing responses and survey weights when relevant.

Strengths

Easy to communicate and well suited to categorical survey variables.

Limitations

Small cells can be unstable; percentages can be misleading when denominators differ or are not reported.

When not to use it

Do not calculate proportions without specifying the denominator or treat correlated observations as independent when estimating uncertainty.

Illustrative research scenario (hypothetical)

Describe numbers and percentages of patients in each insurance category.

Mathematical foundation

Mathematical foundation

descriptive statistic

\(n_k=\sum_{i=1}^{n}\mathbf{1}(X_i=k),\qquad \hat{p}_k=\frac{n_k}{n}\)
View LaTeX source
n_k=\sum_{i=1}^{n}\mathbf{1}(X_i=k),\qquad \hat{p}_k=\frac{n_k}{n}

Symbols

n_k: count in category k; n: total nonmissing cases; 1(·): indicator function.

Explanation

Counts summarize category prevalence; proportions express counts relative to the chosen denominator.

Important scope limitation

Report missing values and weighted denominators explicitly where relevant.

Assumptions and diagnostics

Assumptions and conditions

Categories are defined consistently, mutually interpretable, and linked to a clear denominator; observations or survey weights must reflect the intended population.

Diagnostics to perform

Tabulate each category including missing and unknown responses. Audit denominators, coding, duplicate records, weights, and cells with few observations.

Consequences of violations

Misclassification and inconsistent denominators distort percentages; selection bias prevents valid population prevalence claims.

Diagnostic caveats

A percentage alone does not establish precision. Use design-appropriate intervals and account for clustered or weighted samples if making inferences.

Understanding the results

Primary outputs

Category counts, denominators, proportions or percentages, optionally by subgroup.

Inference and tests

Descriptive only; binomial or multinomial uncertainty may be estimated where sampling assumptions permit.

Effect sizes and intervals

Percentage and its denominator should be reported together; an appropriate confidence interval describes population-proportion uncertainty.

Model fit and performance

Check missing categories, small cells and weighting; no model fit measure is inherent.

Interpreting results

Twenty of 80 participants (25%) fall into the specified category.

Common mistakes

Do not compare percentages without checking denominators or equate raw sample counts with representative population estimates.

Example report wording (placeholder values)

[count]/[denominator] participants ([percent]%) had [category]; [missing] records were missing.

R tutorial

Learning goal

Tabulate binary response frequencies.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

print(table(d$y))
print(prop.table(table(d$y)))

Output to inspect

Counts and sample proportions in each category.

Limitations and checks

Specify denominator and missing-data policy.

Python tutorial

Learning goal

Tabulate binary response frequencies.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

print(d.y.value_counts().sort_index())
print(d.y.value_counts(normalize=True).sort_index())
