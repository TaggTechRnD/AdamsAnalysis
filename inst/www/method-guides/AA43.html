Ordinal Logistic Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Ordinal logistic regression models an ordered categorical outcome, commonly using cumulative odds.

Example research questions

Which factors are associated with reporting greater symptom severity?

Design requirements

Outcome levels have a defensible ordering, appropriate predictors, and assumptions for the selected ordinal link such as proportional odds if used.

Strengths

Exploits ordering without treating category scores as evenly spaced measurements.

Limitations

The proportional-odds assumption may fail; odds ratios require careful direction and threshold interpretation.

When not to use it

Do not treat ordered responses as nominal without reason or assume equal distances between ordinal categories.

Illustrative research scenario (hypothetical)

Model four-level self-rated health using age, activity, and smoking.

Mathematical foundation

Mathematical foundation

cumulative logit model

\(\log\!\left(\frac{P(Y_i\leq k)}{1-P(Y_i\leq k)}\right)=\theta_k-\boldsymbol{x}_i^\top\boldsymbol{\beta}\)
View LaTeX source
\log\!\left(\frac{P(Y_i\leq k)}{1-P(Y_i\leq k)}\right)=\theta_k-\boldsymbol{x}_i^\top\boldsymbol{\beta}

Symbols

k: ordered threshold; θ_k: threshold intercept; β: common coefficient vector.

Explanation

Models cumulative probabilities of an ordered outcome with common slopes across thresholds.

Important scope limitation

The proportional-odds assumption can fail; slope signs follow the shown convention.

Assumptions and diagnostics

Assumptions and conditions

Outcome categories have meaningful order; standard cumulative-logit model assumes proportional odds (common covariate effect across cutpoints), with adequate observations per level.

Diagnostics to perform

Inspect category frequencies, proportional-odds diagnostics and threshold-specific effects; check sparse cells, convergence and predicted-category calibration.

Consequences of violations

A strong proportional-odds violation makes one common odds ratio misleading; empty categories produce unstable estimates.

Diagnostic caveats

The proportional-odds assumption pertains to the standard cumulative-logit form; other ordinal link models impose different assumptions.

Understanding the results

Primary outputs

Cumulative log-odds coefficient(s), threshold parameters and predicted ordinal-category probabilities.

Inference and tests

Coefficient Wald/LR tests and confidence intervals depend on link and proportional-odds specification.

Effect sizes and intervals

Report common odds ratio with interval if proportional-odds model holds, or category-specific contrasts if it does not.

Model fit and performance

Check proportional-odds assumption and ordinal calibration; use appropriate predictive scoring metrics.

Interpreting results

OR above 1 shifts cumulative-category odds according to the software’s stated coding convention.

Common mistakes

The direction of an ordinal OR depends on response ordering and link convention; never assume every OR means higher severity.

Example report wording (placeholder values)

Ordinal OR for [X] = [OR] (95% CI [limits]); outcome ordering = [levels]; proportional odds check = [result].

R tutorial

Learning goal

Model proportional-odds cumulative category probabilities.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

MASS

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

set.seed(2027)
score<-0.8*d$x-0.4*d$treatment+rnorm(nrow(d))
d$grade<-ordered(cut(score,breaks=c(-Inf,-.5,.5,Inf),labels=c("Low","Mid","High")))
fit<-MASS::polr(grade~x+treatment,data=d,method="logistic",Hess=TRUE)
print(summary(fit))

Output to inspect

Common slope odds ratios and estimated thresholds.

Limitations and checks

Test proportional-odds assumption; slope signs depend on cumulative-odds convention.

Python tutorial

Learning goal

Model proportional-odds cumulative category probabilities.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

from statsmodels.miscmodels.ordinal_model import OrderedModel
score=.8*d.x.to_numpy()-.4*d.treatment.to_numpy()+rng.normal(size=len(d))
d["grade"]=np.digitize(score,[-.5,.5])
fit=OrderedModel(d.grade,d[["x","treatment"]],distr="logit").fit(method="bfgs",disp=False)
print(fit.summary())
