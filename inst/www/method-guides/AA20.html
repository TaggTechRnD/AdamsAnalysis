Simple Linear Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Simple linear regression models the expected value of a continuous outcome as a linear function of one predictor.

Example research questions

How much does mean blood pressure change with each additional year of age?

Design requirements

Continuous outcome, one predictor, and a reasonable conditional mean relationship; check independence and residual behavior for inference.

Strengths

Provides an estimated slope in outcome units and supports prediction with uncertainty intervals.

Limitations

Vulnerable to confounding, nonlinear patterns, and influential points; predictive fit does not prove causality.

When not to use it

Do not interpret an observational regression slope as a causal effect without design-based support.

Illustrative research scenario (hypothetical)

Estimate the association between age and systolic blood pressure in a cohort.

Mathematical foundation

Mathematical foundation

linear model

\(Y_i=\beta_0+\beta_1x_i+\varepsilon_i\)
View LaTeX source
Y_i=\beta_0+\beta_1x_i+\varepsilon_i

Symbols

β0: intercept; β1: expected outcome change per one-unit x increase; ε: error.

Explanation

Models the conditional mean outcome as a linear function of one predictor.

Important scope limitation

A linear association alone is not causal; error assumptions matter for inference.

Assumptions and diagnostics

Assumptions and conditions

Predictor and mean outcome have a suitably linear relation; errors have appropriate dependence structure and variance; standard t and F inference uses an adequate error distribution.

Diagnostics to perform

Inspect scatterplot, residual-versus-fit plot, Q-Q plot, residual spread and leverage/Cook distance; evaluate independence from time or cluster design.

Consequences of violations

Curvature biases slope summaries, heteroskedasticity harms conventional standard errors, and influential observations may drive results.

Diagnostic caveats

Residual normality matters most for small-sample classical inference, not for defining the OLS estimates. Association is not causation.

Understanding the results

Primary outputs

Intercept and slope estimate, standard error, t statistic, fitted line and residuals.

Inference and tests

Slope confidence interval and p-value test linear association under the regression error model.

Effect sizes and intervals

Report change in outcome units per one-unit change in predictor, with confidence interval and units.

Model fit and performance

R²/adjusted R² and residual summaries describe in-sample fit; out-of-sample RMSE assesses prediction when validated.

Interpreting results

A slope of 2 means expected Y rises by 2 units for each one-unit increase in X under the model.

Common mistakes

Association is not causation; a high R² does not guarantee unbiased coefficients or good extrapolation.

Example report wording (placeholder values)

Linear slope β = [estimate] [Y units/X unit] (95% CI [lower], [upper]; p = [p]); R² = [R2].

R tutorial

Learning goal

Estimate a linear slope relating x to continuous y.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

fit<-lm(y~x,data=d)
print(summary(fit))
print(confint(fit))

Output to inspect

Regression slope, CI and R-squared.

Limitations and checks

Review residual assumptions; slope does not imply a causal relationship.

Python tutorial

Learning goal

Estimate a linear slope relating x to continuous y.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.formula.api as smf
fit=smf.ols("y ~ x",data=d).fit()
print(fit.summary())
