Support Vector Machine (SVM)

Statistical method reference guide

Overview and appropriate use

Purpose

Support vector machines find separating margins or predictive functions, optionally using kernels to represent nonlinear boundaries.

Example research questions

Can sensor-derived features classify individuals with high fall risk?

Design requirements

Labeled observations, suitable numeric feature representation, appropriate scaling, and tuning and validation of kernel and penalty settings.

Strengths

Flexible classification with strong performance in many moderate-sized high-dimensional datasets.

Limitations

Kernel models can be difficult to explain and can struggle with unscaled features or large datasets.

When not to use it

Do not use accuracy alone for strongly imbalanced outcomes or treat the margin as a calibrated probability.

Illustrative research scenario (hypothetical)

Classify fall-risk categories using wearable sensor measurements.

Mathematical foundation

Mathematical foundation

margin optimization

\(\min_{w,b,\xi}\frac{1}{2}\lVert w\rVert^2+C\sum_i\xi_i\quad\mathrm{s.t.}\quad y_i(w^\top\phi(x_i)+b)\geq1-\xi_i\)

\min_{w,b,\xi}\frac{1}{2}\lVert w\rVert^2+C\sum_i\xi_i\quad\mathrm{s.t.}\quad y_i(w^\top\phi(x_i)+b)\geq1-\xi_i

Symbols

y_i in {−1,1}: class; φ: feature map; ξ_i≥0: margin violations; C: penalty.

Explanation

A soft-margin support vector classifier balances a wide margin against classification errors.

Important scope limitation

This is classification SVM; support vector regression and other loss functions use different objectives.

Assumptions and diagnostics

Assumptions and conditions

Predictor scaling, kernel and penalty settings are chosen appropriately for the objective; evaluation is separated from tuning.

Diagnostics to perform

Inspect scaled feature ranges, kernel/regularization grid, training versus validation performance, class imbalance, calibration and leakage.

Consequences of violations

Poor scaling or kernel tuning makes boundaries unstable and out-of-sample accuracy optimistic.

Diagnostic caveats

SVM does not generally provide calibrated probabilities without an additional calibration step.

Understanding the results

Primary outputs

Decision scores or predicted labels; support-vector counts, kernel and hyperparameters.

Inference and tests

Standard SVM is not a hypothesis-testing procedure; probability estimates require calibration.

Effect sizes and intervals

Report margins or calibrated probabilities and corresponding uncertainty from appropriate validation where possible.

Model fit and performance

Use held-out accuracy/F1/AUC and class-specific sensitivity, specificity or regression RMSE; tune within validation.

Interpreting results

A larger decision score generally indicates the prediction lies further toward one class side of the separating boundary.

Common mistakes

SVM decision scores are not automatically probabilities, and accuracy alone can mislead with class imbalance.

Example report wording (placeholder values)

SVM [kernel], tuned C = [value]; held-out sensitivity = [value], specificity = [value], AUC = [value].

R tutorial

Learning goal

Learn a nonlinear decision boundary with a support-vector machine.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

e1071

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

fit<-e1071::svm(y~x1+x2+x3,data=train,kernel="radial",cost=1)
p<-predict(fit,test)
print(table(truth=test$y,predicted=p))

Output to inspect

Test accuracy/confusion and sensitivity to hyperparameters.

Limitations and checks

Scale predictors and tune C/gamma before deployment; outputs are not calibrated probabilities.

Python tutorial

Learning goal

Learn a nonlinear decision boundary with a support-vector machine.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.svm import SVC
from sklearn.metrics import accuracy_score
fit=SVC(kernel="rbf",C=1,random_state=2026).fit(train[["x1","x2","x3"]],train.y)
print("Test accuracy:",accuracy_score(test.y,fit.predict(test[["x1","x2","x3"]])))
