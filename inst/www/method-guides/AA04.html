Pearson Correlation

Statistical method reference guide

Overview and appropriate use

Purpose

Pearson correlation quantifies the direction and strength of linear association between two numeric variables.

Example research questions

Are measured height and weight linearly associated in this sample?

Design requirements

Two quantitative variables measured on comparable observations; interpretation depends on a roughly linear pattern and influential observations.

Strengths

Simple standardized description of a linear relationship, with a familiar range from -1 to 1.

Limitations

Sensitive to outliers; a low correlation does not rule out a nonlinear association and correlation is not causation.

When not to use it

Do not use as proof that one variable causes the other or as the sole summary of a strongly curved relationship.

Illustrative research scenario (hypothetical)

Examine the linear association between age and systolic blood pressure.

Mathematical foundation

Mathematical foundation

association statistic

\(r=\frac{\sum_i(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum_i(x_i-\bar{x})^2\sum_i(y_i-\bar{y})^2}}\)

Symbols

x_i, y_i: paired observations; x-bar, y-bar: sample means.

Explanation

Pearson r quantifies the direction and strength of a linear association.

Important scope limitation

Correlation does not establish causation; nonlinear patterns and influential points may mislead.

Assumptions and diagnostics

Assumptions and conditions

Paired continuous measurements are meaningful; Pearson correlation measures linear association. Conventional small-sample significance tests usually assume independent pairs and bivariate normality.

Diagnostics to perform

Plot x against y, inspect curvature and influential points, and examine residual patterns if fitting a line. Assess independence by the study design and inspect distributional shape for small-sample inference.

Consequences of violations

A few extremes or a curved association can distort the coefficient; dependence and distributional misspecification can invalidate standard p-values or intervals.

Diagnostic caveats

Correlation is not causation. For inference, bivariate normality can sometimes be relaxed with adequate samples or suitable resampling.

Understanding the results

Primary outputs

Pearson correlation r, sample size and optionally a scatterplot.

Inference and tests

Test of zero population linear correlation typically uses a t statistic and p-value; confidence intervals often use Fisher z under suitable assumptions.

Effect sizes and intervals

r ranges from −1 to +1; report a confidence interval for the correlation and consider r² only as the shared linear variation in a simple bivariate setting.

Model fit and performance

Inspect scatterplot for linearity and influential observations; correlation is not assessed by regression fit metrics alone.

Interpreting results

Positive r indicates that larger X tends to accompany larger Y in an approximately linear pattern.

Common mistakes

A large correlation does not establish causality, and r near zero does not rule out a nonlinear association.

Example report wording (placeholder values)

X and Y had Pearson r = [r] (95% CI [lower], [upper]; n = [n]; p = [p]).

R tutorial

Learning goal

Estimate linear association between two measurements.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

print(cor.test(d$x,d$y,method="pearson"))

Output to inspect

Pearson r and p-value; inspect a scatterplot separately.

Limitations and checks

Linear association is not causal; extreme points can dominate.

Python tutorial

Learning goal

Estimate linear association between two measurements.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
print(stats.pearsonr(d.x,d.y))
