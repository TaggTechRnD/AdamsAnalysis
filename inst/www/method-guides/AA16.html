Kruskal-Wallis Test

Statistical method reference guide

Overview and appropriate use

Purpose

Kruskal-Wallis tests whether independently sampled groups differ in their rank distributions.

Example research questions

Do ordered pain ratings differ across four independent treatment groups?

Design requirements

Three or more independent groups with ordinal or quantitative outcomes; a common-shape assumption is needed for a simple location interpretation.

Strengths

Rank-based omnibus comparison without a normal-outcome assumption.

Limitations

Does not show which groups differ, and distribution shape differences can drive the result.

When not to use it

Do not use it for repeated measurements or interpret every significant test as a difference in medians.

Illustrative research scenario (hypothetical)

Compare patient satisfaction rankings across four hospitals.

Mathematical foundation

Mathematical foundation

rank test statistic

\(H=\frac{12}{N(N+1)}\sum_{j=1}^{k}n_j\left(\bar{R}_j-\frac{N+1}{2}\right)^2\)
View LaTeX source
H=\frac{12}{N(N+1)}\sum_{j=1}^{k}n_j\left(\bar{R}_j-\frac{N+1}{2}\right)^2

Symbols

k: groups; N: total size; n_j: group size; R-bar_j: mean pooled rank in group j.

Explanation

Compares distributions across independent groups using ranks.

Important scope limitation

Shown without tie correction; it is not inherently a test of medians unless shapes are comparable.

Assumptions and diagnostics

Assumptions and conditions

Independent groups and outcome values with meaningful ordering. Comparing group medians specifically requires similarly shaped distributions.

Diagnostics to perform

Inspect ECDFs, boxplots, ties, group sizes and rank distributions; establish independent group assignment from design.

Consequences of violations

Dependent observations invalidate ordinary p-values; different distribution shapes weaken interpretations as a median-only effect.

Diagnostic caveats

Kruskal-Wallis detects differences in rank distributions, not exclusively medians. Significant omnibus results do not identify which groups differ.

Understanding the results

Primary outputs

Kruskal–Wallis H statistic, degrees of freedom, group rank summaries and p-value.

Inference and tests

Omnibus rank test asks whether independent-group distributions differ; follow-up rank comparisons need multiplicity control.

Effect sizes and intervals

Report rank-based effect size (e.g., epsilon-squared) and an appropriate interval if supported.

Model fit and performance

Examine distribution shapes, ties and sample sizes; no model fit metric.

Interpreting results

An overall difference in ranks indicates groups are not distributed identically.

Common mistakes

Do not label the H test a general test of median differences unless comparable distribution shapes support that interpretation.

Example report wording (placeholder values)

Kruskal–Wallis H([df]) = [H], p = [p], ε² = [effect]; post-hoc comparisons [method].

R tutorial

Learning goal

Compare rank distributions among independent groups.

Simulated data

Two independent categorical factors with an interaction on a continuous outcome.

Packages

stats

R example

set.seed(2026)
d <- expand.grid(group = factor(c("Control","Treatment")),
                 dose = factor(c("Low","High")), rep = seq_len(40))
d$y <- 10 + 2*(d$group == "Treatment") + 1*(d$dose == "High") +
  2*(d$group == "Treatment")*(d$dose == "High") + rnorm(nrow(d), sd = 2)

print(kruskal.test(y ~ group,data=d))

Output to inspect

Kruskal–Wallis H and p-value.

Limitations and checks

Does not automatically test equality of medians for differing distribution shapes.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
d = pd.MultiIndex.from_product([["Control","Treatment"],["Low","High"],range(40)],
                               names=["group","dose","rep"]).to_frame(index=False)
d["y"] = (10 + 2*(d.group == "Treatment") + (d.dose == "High") +
          2*(d.group == "Treatment")*(d.dose == "High") + rng.normal(0, 2, len(d)))

from scipy import stats
samples=[part.y.to_numpy() for _,part in d.groupby("group")]
print(stats.kruskal(*samples))
