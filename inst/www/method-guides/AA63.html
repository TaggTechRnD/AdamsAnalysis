LASSO Regression

Statistical method reference guide

Overview and appropriate use

Purpose

LASSO adds an L1 penalty that can shrink some regression coefficients to zero, enabling regularization and variable selection.

Example research questions

Which of many baseline predictors contribute to out-of-sample prediction of functional decline?

Design requirements

Defined response and model family, candidate predictors, standardized design as appropriate, and out-of-sample tuning.

Strengths

Can build compact prediction models and reduce overfitting in high-dimensional settings.

Limitations

Variable selection can be unstable with highly correlated predictors, and post-selection inference requires care.

When not to use it

Do not treat selected predictors as proven causal drivers or report ordinary p-values after data-driven selection without adjustment.

Illustrative research scenario (hypothetical)

Select a parsimonious subset of survey variables for predicting follow-up health scores.

Mathematical foundation

Mathematical foundation

penalized optimization

\(\hat{\boldsymbol{\beta}}=\arg\min_{\boldsymbol{\beta}}\left\{\sum_i(y_i-\beta_0-\boldsymbol{x}_i^\top\boldsymbol{\beta})^2+\lambda\sum_j|\beta_j|\right\}\)
View LaTeX source
\hat{\boldsymbol{\beta}}=\arg\min_{\boldsymbol{\beta}}\left\{\sum_i(y_i-\beta_0-\boldsymbol{x}_i^\top\boldsymbol{\beta})^2+\lambda\sum_j|\beta_j|\right\}

Symbols

λ≥0: tuning penalty; β_j: non-intercept coefficients.

Explanation

LASSO’s absolute-value penalty can shrink some coefficients exactly to zero.

Important scope limitation

Variable selection may be unstable with correlated predictors; inference after selection needs care.

Assumptions and diagnostics

Assumptions and conditions

Response family/link is suitable; predictors have consistent scaling, and lambda selection respects validation and dependence structure.

Diagnostics to perform

Inspect standardized predictors, cross-validation folds, model stability across folds, validation error and correlated features.

Consequences of violations

Improper scaling or unstable tuning produces fragile variable selection and unreliable prediction.

Diagnostic caveats

LASSO variable selection is unstable among correlated predictors; naive post-selection p-values are generally invalid.

Understanding the results

Primary outputs

LASSO coefficients, nonzero selected predictors, chosen λ and validation predictions.

Inference and tests

Naive post-selection p-values/CIs are not valid without methods addressing selection.

Effect sizes and intervals

Report coefficient selection stability and predictive contrasts, not uncorrected inferential claims.

Model fit and performance

Cross-validated RMSE/deviance or holdout metrics; selected λ and nonzero coefficient count.

Interpreting results

A coefficient shrunk to zero means this penalty setting excluded its contribution, not that the true effect is exactly zero.

Common mistakes

Selection can change with small data perturbations, especially for correlated predictors; scaling strongly matters.

Example report wording (placeholder values)

LASSO at λ = [lambda] retained [k] predictors; validation [metric] = [value].

R tutorial

Learning goal

Select/shrink predictors using the L1 penalty.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

glmnet

R example

set.seed(2026)
n <- 300
x1<-rnorm(n); x2<-rnorm(n); x3<-rnorm(n)
y<-3 + 2*x1 - x2 + 0.7*x3 + rnorm(n,sd=1.5)
d<-data.frame(y,x1,x2,x3)
idx<-sample(seq_len(n),round(.7*n))
train<-d[idx,];test<-d[-idx,]

X<-as.matrix(train[c("x1","x2","x3")])
fit<-glmnet::cv.glmnet(X,train$y,alpha=1,nfolds=5)
print(coef(fit,s="lambda.min"))
p<-as.numeric(predict(fit,s="lambda.min",newx=as.matrix(test[c("x1","x2","x3")])))
print(mean((p-test$y)^2))

Output to inspect

Nonzero coefficients, chosen penalty and holdout prediction error.

Limitations and checks

Variable selection may be unstable across samples; naive post-selection p-values are invalid.

Python tutorial

Learning goal

Select/shrink predictors using the L1 penalty.

Simulated data

Continuous prediction outcome and three features, with a held-out test set.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng=np.random.default_rng(2026)
n=300
x1=rng.normal(size=n);x2=rng.normal(size=n);x3=rng.normal(size=n)
y=3+2*x1-x2+.7*x3+rng.normal(0,1.5,n)
d=pd.DataFrame({"y":y,"x1":x1,"x2":x2,"x3":x3})
train,test=train_test_split(d,test_size=.3,random_state=2026)

from sklearn.linear_model import LassoCV
from sklearn.metrics import mean_squared_error
cols=["x1","x2","x3"]
fit=LassoCV(cv=5,random_state=2026,max_iter=5000).fit(train[cols],train.y)
print("Coefficients:",fit.coef_)
print("Test MSE:",mean_squared_error(test.y,fit.predict(test[cols])))
