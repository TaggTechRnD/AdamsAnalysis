McNemar's Test

Statistical method reference guide

Overview and appropriate use

Purpose

McNemar's test assesses whether the marginal probability of a binary response differs between two matched occasions or conditions.

Example research questions

Does the proportion of patients screening positive change after an intervention?

Design requirements

Binary outcomes recorded twice on the same people or properly matched pairs, with a paired two-by-two table.

Strengths

Focuses on discordant pairs and correctly handles within-pair dependence.

Limitations

Limited to paired binary comparisons; conventional versions are unsuitable for complex clusters or more than two occasions.

When not to use it

Do not use an independent-samples chi-square test on paired yes-no responses.

Illustrative research scenario (hypothetical)

Compare smoking status before and after counseling for the same participants.

Mathematical foundation

Mathematical foundation

test statistic

\(\chi^2_M=\frac{(b-c)^2}{b+c}\)
View LaTeX source
\chi^2_M=\frac{(b-c)^2}{b+c}

Symbols

b,c: discordant off-diagonal cell counts in a paired 2×2 table.

Explanation

Tests whether paired binary responses change symmetrically across categories.

Important scope limitation

This is the asymptotic uncorrected form; sparse discordant pairs favor an exact version.

Assumptions and diagnostics

Assumptions and conditions

Binary responses occur in correctly matched pairs and sampling pairs are independent. Discordant pairs provide the information for McNemar inference.

Diagnostics to perform

Construct a paired 2x2 table, verify subject matching, count discordant pairs and choose exact or asymptotic method accordingly.

Consequences of violations

Very few discordant pairs make large-sample chi-square approximations inaccurate; mispaired responses make inference invalid.

Diagnostic caveats

McNemar targets marginal discordance rather than an ordinary two-independent-samples association.

Understanding the results

Primary outputs

2×2 paired binary table, discordant-pair counts and McNemar test statistic/p-value.

Inference and tests

Tests equality of two marginal binary proportions under paired observations; exact variant can be used for few discordant pairs.

Effect sizes and intervals

Report paired proportion difference with suitable interval and/or matched-pair odds ratio with its definition.

Model fit and performance

Inspect pairing, discordant counts and sampling; no predictive model-fit statistic.

Interpreting results

More changes from no→yes than yes→no indicates a net shift in positive responses.

Common mistakes

McNemar does not analyze two independent groups; concordant pairs do not drive the basic test statistic.

Example report wording (placeholder values)

Discordant pairs: no→yes = [b], yes→no = [c]; McNemar p = [p]; paired difference = [diff].

R tutorial

Learning goal

Test change in a paired binary characteristic.

Simulated data

90 participants with correlated baseline and follow-up blood-pressure readings.

Packages

stats

R example

set.seed(2026)
n <- 90
before <- rnorm(n, mean = 125, sd = 13)
after <- before - 5 + rnorm(n, sd = 7)
d <- data.frame(id = seq_len(n), before, after)

set.seed(2026)
d$pre<-rbinom(nrow(d),1,.35)
d$post<-ifelse(d$pre==1,rbinom(nrow(d),1,.70),rbinom(nrow(d),1,.23))
print(mcnemar.test(table(d$pre,d$post)))

Output to inspect

McNemar p-value based on discordant pairs.

Limitations and checks

Within-person paired 2×2 table is required; independent chi-square is inappropriate.

Python tutorial

Learning goal

Test change in a paired binary characteristic.

Simulated data

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
before = rng.normal(125, 13, n)
after = before - 5 + rng.normal(0, 7, n)
d = pd.DataFrame({"id": np.arange(n), "before": before, "after": after})

from statsmodels.stats.contingency_tables import mcnemar
pre=rng.binomial(1,.35,len(d))
post=np.where(pre==1,rng.binomial(1,.70,len(d)),rng.binomial(1,.23,len(d)))
ct=pd.crosstab(pre,post).reindex(index=[0,1],columns=[0,1],fill_value=0)
print(mcnemar(ct.to_numpy(),exact=False,correction=True))
