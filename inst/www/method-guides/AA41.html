Generalized Additive Model (GAM)

Statistical method reference guide

Overview and appropriate use

Purpose

Generalized additive models use smooth functions of predictors to describe potentially nonlinear conditional relationships.

Example research questions

Is the association between daily temperature and hospital admissions nonlinear?

Design requirements

A suitable outcome family and link, predictors with enough coverage to estimate smooth trends, and attention to dependence and confounding.

Strengths

Captures curved exposure-response patterns without specifying one polynomial shape.

Limitations

Smoothing choices and concurvity complicate interpretation; fitted curves can overfit or obscure causal confounding.

When not to use it

Do not treat smooth associations as causal effects without design support or use complicated smooths with sparse predictor coverage.

Illustrative research scenario (hypothetical)

Estimate a smooth relation between ambient temperature and emergency visits.

Mathematical foundation

Mathematical foundation

additive predictor

\(g(E[Y_i])=\beta_0+\sum_{j=1}^{p}f_j(x_{ij})\)
View LaTeX source
g(E[Y_i])=\beta_0+\sum_{j=1}^{p}f_j(x_{ij})

Symbols

g: link function; f_j: smooth function of predictor j; β0: intercept.

Explanation

GAMs add flexible smooth relationships rather than imposing a strictly linear predictor effect.

Important scope limitation

Smoothing flexibility and inference depend on basis and penalty choices; additive terms omit interactions unless specified.

Assumptions and diagnostics

Assumptions and conditions

Selected smooth terms represent plausible relationships; smoothing parameters, error family/link and dependence structure suit the data.

Diagnostics to perform

Review estimated smooths with confidence bands, basis-dimension diagnostics, effective degrees of freedom, residual plots and out-of-sample performance.

Consequences of violations

Under-smoothing overfits; excessive smoothing hides nonlinear effects; wrong family or residual dependence affects inference.

Diagnostic caveats

A flexible smooth does not remove confounding. Basis checks and smoothness selection are separate issues.

Understanding the results

Primary outputs

Smooth-function estimates and plots, effective degrees of freedom (EDF), fitted values and uncertainty bands.

Inference and tests

Approximate smooth-term tests/p-values depend on smoothing selection and model family; avoid overinterpreting exploratory smooths.

Effect sizes and intervals

Report meaningful predicted contrasts or derivative estimates with uncertainty bands, not only a smooth-term p-value.

Model fit and performance

Deviance explained, adjusted R² where meaningful, residual diagnostics and held-out predictive error.

Interpreting results

EDF above one can indicate nonlinear complexity, while the smooth plot shows its estimated shape.

Common mistakes

EDF is not a conventional coefficient or effect size; smoothing bands are not evidence of causality.

Example report wording (placeholder values)

Smooth of [X]: EDF = [edf], approximate p = [p]; predicted outcome difference [x1]→[x2] = [diff].

R tutorial

Learning goal

Estimate a smooth nonlinear relationship.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

mgcv

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

fit<-mgcv::gam(y~s(x,k=10),data=d,method="REML")
print(summary(fit))

Output to inspect

Estimated smooth, effective degrees of freedom, and uncertainty.

Limitations and checks

Smooth significance can be optimistic without adequate model checks; R and Python smoothing defaults differ.

Simulated data

Packages

numpy, pandas, pygam

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

# Install optional dependency beforehand: pip install pygam
from pygam import LinearGAM, s
fit=LinearGAM(s(0,n_splines=10)).fit(d[["x"]].to_numpy(),d.y.to_numpy())
print(fit.summary())
