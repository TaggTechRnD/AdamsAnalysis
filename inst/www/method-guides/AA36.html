One-Sample t-Test

Statistical method reference guide

Overview and appropriate use

Purpose

One-sample t-test compares a sample mean with a prespecified reference value.

Example research questions

Is the average resting heart rate in a cohort different from a clinically specified benchmark?

Design requirements

Numeric measurements, a meaningful prespecified reference mean, and independent observations supporting inference about the mean.

Strengths

Simple estimation and hypothesis test for deviation from a target value.

Limitations

Sensitive to extreme values and small-sample nonnormality; the benchmark may not represent a relevant comparison population.

When not to use it

Do not use an arbitrary post hoc reference value as though it were a prespecified standard.

Illustrative research scenario (hypothetical)

Test whether average daily sodium intake differs from a stated guideline level.

Mathematical foundation

Mathematical foundation

test statistic

\(t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}\)
View LaTeX source
t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}

Symbols

x-bar: sample mean; μ0: hypothesized population mean; s: sample SD; n: sample size.

Explanation

Tests a sample mean against a prespecified reference value.

Important scope limitation

Independence and sampling distribution assumptions determine validity of the t approximation.

Assumptions and diagnostics

Assumptions and conditions

Independent observations with a continuous outcome and a prespecified reference mean; small-sample classical t inference assumes roughly normal population errors.

Diagnostics to perform

Review histogram/Q-Q plot, outliers, sampling independence, sample size and the origin of the reference value.

Consequences of violations

Outliers or strong skew can distort small-sample inference; dependence invalidates the usual standard error.

Diagnostic caveats

The reference mean should not be chosen after seeing the data without accounting for selection.

Understanding the results

Primary outputs

Sample mean, reference value, one-sample t statistic and degrees of freedom.

Inference and tests

Tests whether a population mean equals a prespecified reference value.

Effect sizes and intervals

Mean difference from reference and 95% confidence interval; optionally standardized effect d with its definition.

Model fit and performance

Inspect observations, outliers and sample-distribution concerns; no model fit index.

Interpreting results

A difference of +5 indicates the sample mean is five measurement units above the prespecified reference.

Common mistakes

Failure to reject does not establish equivalence, and data-driven reference choices invalidate ordinary p-value interpretation.

Example report wording (placeholder values)

Mean − reference = [diff] [units] (95% CI [lower], [upper]); t([df]) = [t], p = [p].

R tutorial

Learning goal

Compare sample mean with a prespecified benchmark of 10.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

print(t.test(d$y,mu=10))

Output to inspect

Mean difference, t statistic, p-value, CI.

Limitations and checks

Benchmark must be prespecified; independence still matters.

Python tutorial

Learning goal

Compare sample mean with a prespecified benchmark of 10.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

from scipy import stats
print(stats.ttest_1samp(d.y,popmean=10))
