Binary Logistic Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Binary logistic regression models the log-odds of one of two outcome categories as a function of predictors.

Example research questions

Which clinical factors are associated with diabetes diagnosis?

Design requirements

Binary outcome, appropriately coded predictors, a plausible logit specification, and enough outcome events for stable estimates.

Strengths

Naturally accommodates mixed predictor types and yields odds ratios or predicted probabilities.

Limitations

Sparse events, separation, and misspecified nonlinear relationships can impair estimates; odds ratios are not risk ratios.

When not to use it

Do not apply directly to a multinomial outcome or interpret an odds ratio as a probability difference.

Illustrative research scenario (hypothetical)

Model current smoking status using age, sex, and socioeconomic indicators.

Mathematical foundation

Mathematical foundation

generalized linear model

\(\log\!\left(\frac{p_i}{1-p_i}\right)=\beta_0+\boldsymbol{x}_i^\top\boldsymbol{\beta}\)
View LaTeX source
\log\!\left(\frac{p_i}{1-p_i}\right)=\beta_0+\boldsymbol{x}_i^\top\boldsymbol{\beta}

Symbols

p_i=P(Y_i=1|x_i); β: log-odds coefficients; exp(β): conditional odds ratios.

Explanation

Links binary outcome probability to predictors through the log-odds.

Important scope limitation

Odds ratios differ from risk ratios; fitted probabilities need not demonstrate calibration or causality.

Assumptions and diagnostics

Assumptions and conditions

Binary outcome with valid event coding; specified predictors and approximately linear relationships on logit scale for continuous terms; no complete separation.

Diagnostics to perform

Check outcome counts and events per modeled parameter, cross-tabs for separation, logit-linearity plots or spline checks, deviance residuals and calibration.

Consequences of violations

Separation causes infinite or unstable coefficients; sparse events and logit misspecification distort intervals and predicted probabilities.

Diagnostic caveats

Normality of the binary outcome is not required. Adequate events per parameter depend on data, complexity and estimation strategy.

Understanding the results

Primary outputs

Log-odds coefficients, odds ratios (ORs), standard errors and predicted probabilities.

Inference and tests

Wald or likelihood-ratio tests assess terms; confidence intervals can be obtained on log-odds or OR scale.

Effect sizes and intervals

Report adjusted OR with 95% CI and, where possible, meaningful absolute-risk differences or predicted probabilities.

Model fit and performance

Calibration, discrimination (AUC), log loss and validation address prediction; pseudo-R² is not ordinary variance explained.

Interpreting results

OR 1.5 corresponds to 50% higher odds, not necessarily 50% higher risk.

Common mistakes

Do not interpret ORs as risk ratios or infer performance from an in-sample classification cutoff alone.

Example report wording (placeholder values)

Adjusted OR for [X] = [OR] (95% CI [lower], [upper]; p = [p]); validated AUC = [AUC] if predictive.

R tutorial

Learning goal

Model the probability of a binary outcome through log-odds.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

fit<-glm(y~x+treatment,data=d,family=binomial())
print(summary(fit))
print(exp(coef(fit)))

Output to inspect

Log-odds coefficients, odds ratios and uncertainty.

Limitations and checks

Odds ratios are not risk ratios; check separation and calibration.

Python tutorial

Learning goal

Model the probability of a binary outcome through log-odds.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

import statsmodels.formula.api as smf
fit=smf.logit("y ~ x + treatment",data=d).fit(disp=False)
print(fit.summary())
print("Odds ratios:\n",np.exp(fit.params))
