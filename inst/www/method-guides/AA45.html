Zero-Inflated Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Zero-inflated regression combines a count model with a separate process that can produce additional structural zeros.

Example research questions

Are there both communities with no possibility of an event and others with stochastic event counts?

Design requirements

Nonnegative counts, a substantively defensible second zero-generating mechanism, identifiable model components, and suitable covariates.

Strengths

Can represent distinct sources of zero outcomes when warranted by the data-generating process.

Limitations

Extra zeros alone do not prove a zero-inflated process; estimation and interpretation can be unstable.

When not to use it

Do not automatically choose zero inflation merely because many observed counts equal zero.

Illustrative research scenario (hypothetical)

Model annual clinic visits when some participants cannot access the service at all.

Mathematical foundation

Mathematical foundation

mixture distribution

\(P(Y=0)=\pi+(1-\pi)e^{-\mu},\quad P(Y=k>0)=(1-\pi)\frac{e^{-\mu}\mu^k}{k!}\)
View LaTeX source
P(Y=0)=\pi+(1-\pi)e^{-\mu},\quad P(Y=k>0)=(1-\pi)\frac{e^{-\mu}\mu^k}{k!}

Symbols

π: structural-zero probability; μ: mean of the Poisson count component; k: positive count.

Explanation

A zero-inflated Poisson model combines a structural-zero process with an ordinary count process.

Important scope limitation

This is one type of zero-inflated regression; zero-inflated negative binomial uses a different count component.

Assumptions and diagnostics

Assumptions and conditions

Counts include a defensible separate structural-zero mechanism and a sampling count process; both model components are identifiable from the study design and covariates.

Diagnostics to perform

Compare observed and fitted zero counts, inspect simulation-based residuals and convergence, consider hurdle or ordinary count alternatives, and assess component interpretability.

Consequences of violations

Without an identifiable extra-zero process, zero-inflated parameters are unstable or misleading; misspecification distorts counts and predicted zeros.

Diagnostic caveats

Many observed zeros alone do not establish structural zero inflation. Non-nested comparisons require care.

Understanding the results

Primary outputs

Separate count-model and zero-inflation component estimates, predicted zero probability and conditional count mean.

Inference and tests

Wald/LR tests can examine model terms; tests at boundaries or comparing non-nested models require suitable methodology.

Effect sizes and intervals

Report component-specific coefficients/IRRs or ORs with intervals and marginal predicted count contrasts.

Model fit and performance

Compare observed and predicted zero frequencies, calibration and suitable information criteria/validated log scores.

Interpreting results

A predictor can affect the structural-zero component differently from the count-generating component.

Common mistakes

Do not treat count-component IRR as the marginal overall mean ratio or assume observed zeros prove a separate zero-generating process.

Example report wording (placeholder values)

Count-component IRR([X]) = [value]; zero-component OR([X]) = [value]; fitted P(Y=0) = [value].

R tutorial

Learning goal

Fit distinct processes for zero inflation and positive count intensity.

Simulated data

Counts observed over differing exposure durations with an association between rate and covariate.

Packages

pscl

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
exposure <- runif(n, 0.5, 2)
mu <- exp(0.5 + 0.6*x + log(exposure))
y <- rpois(n, lambda = mu)
d <- data.frame(y, x, exposure)

set.seed(2027)
d$y[runif(nrow(d)) < .4] <- 0L
fit<-pscl::zeroinfl(y~x|x,data=d,dist="poisson")
print(summary(fit))

Output to inspect

Inflation and count-part coefficients.

Limitations and checks

Check whether a separate zero-generating process is theoretically justified; optimization can be unstable.

Packages

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
exposure = rng.uniform(.5, 2, n)
mu = np.exp(.5 + .6*x + np.log(exposure))
y = rng.poisson(mu)
d = pd.DataFrame({"y":y,"x":x,"exposure":exposure})

from statsmodels.discrete.count_model import ZeroInflatedPoisson
import statsmodels.api as sm
mask=rng.uniform(size=len(d))<.4
d.loc[mask,"y"]=0
X=sm.add_constant(d[["x"]])
fit=ZeroInflatedPoisson(d.y,X,exog_infl=X,inflation="logit").fit(disp=False)
print(fit.summary())
