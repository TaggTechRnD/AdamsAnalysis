Linear Mixed-Effects Model

Statistical method reference guide

Overview and appropriate use

Purpose

Linear mixed-effects models combine population-level fixed effects with random effects to account for grouped or repeatedly measured continuous outcomes.

Example research questions

How does average blood pressure change over time when patients have different starting levels?

Design requirements

Continuous outcome with genuine clustering or repeated measurements, identifiable grouping variables, and an appropriate fixed- and random-effects structure.

Strengths

Accommodates within-group correlation, unequal visit counts, and subject-specific variation.

Limitations

Results depend on random-effects structure, distributional assumptions, and missing-data mechanisms; complex models may fail to converge.

When not to use it

Do not fit unsupported random-effects structures or interpret random effects as correcting all confounding.

Illustrative research scenario (hypothetical)

Model repeated fitness measurements with participant-specific intercepts and treatment-by-time effects.

Mathematical foundation

Mathematical foundation

mixed-effects model

\(\boldsymbol{y}=X\boldsymbol{\beta}+Z\boldsymbol{b}+\boldsymbol{\varepsilon}\)
View LaTeX source
\boldsymbol{y}=X\boldsymbol{\beta}+Z\boldsymbol{b}+\boldsymbol{\varepsilon}

Symbols

Xβ: fixed effects; Zb: group or subject-specific random effects; ε: residual errors.

Explanation

Models continuous outcomes with correlations induced by repeated or clustered measurements.

Important scope limitation

Random-effect distribution and residual covariance assumptions affect inference; random effects are not always identifiable.

Assumptions and diagnostics

Assumptions and conditions

Observations have valid subject or cluster identifiers. Random-effects/correlation structure and conditional mean model are appropriate; Gaussian LMM inference typically assumes suitable conditional residual behavior.

Diagnostics to perform

Review repeated-measure structure and cluster counts, random-effect variance or singular-fit warnings, conditional residual versus fitted and Q-Q plots, and missingness patterns.

Consequences of violations

Wrong grouping or covariance structure biases standard errors; few clusters weaken uncertainty estimates; informative missingness may bias longitudinal comparisons.

Diagnostic caveats

Normality of raw outcomes is not the requirement; examine conditional residuals. Missing-at-random assumptions cannot be demonstrated from observed data alone.

Understanding the results

Primary outputs

Fixed-effect coefficients, random-effect variance components, subject-specific fitted values and residual variance.

Inference and tests

Conditional fixed-effect intervals/tests depend on degrees-of-freedom or likelihood procedure; report method used.

Effect sizes and intervals

Report key fixed contrasts with intervals and variance components; intraclass correlation can summarize clustering for relevant models.

Model fit and performance

Residual diagnostics and marginal/conditional R² or AIC (comparable likelihood fits) can inform model assessment.

Interpreting results

A fixed time-by-group coefficient estimates modeled average difference in change while random intercepts reflect subject heterogeneity.

Common mistakes

Do not treat random effects as independent participant observations or compare REML likelihoods across differing fixed-effect structures.

Example report wording (placeholder values)

Fixed group × time β = [estimate] [units] (95% CI [lower], [upper]); random-intercept SD = [SD].

R tutorial

Learning goal

Fit correlated repeated measurements using a random participant intercept.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

lme4

R example

set.seed(2026)
n <- 90
d <- expand.grid(id = seq_len(n), time = factor(c("Baseline","Week6","Week12"),
                 levels=c("Baseline","Week6","Week12")))
d$group <- factor(ifelse(d$id <= n/2, "Control", "Treatment"))
subject_effect <- rnorm(n, sd = 3)
d$y <- 30 + subject_effect[d$id] + 1.2*(as.integer(d$time)-1) +
  2*(d$group == "Treatment")*(as.integer(d$time)-1) + rnorm(nrow(d), sd=2)

fit<-lme4::lmer(y~group*time+(1|id),data=d,REML=FALSE)
print(summary(fit))

Output to inspect

Fixed group/time/interaction effects and random intercept variance.

Limitations and checks

Random-effects structure and missingness assumptions require checking.

Python tutorial

Learning goal

Fit correlated repeated measurements using a random participant intercept.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
d = pd.MultiIndex.from_product([range(n), ["Baseline","Week6","Week12"]],
                               names=["id","time"]).to_frame(index=False)
d["group"] = np.where(d.id < n // 2, "Control", "Treatment")
subject_effect = rng.normal(0, 3, n)
t = d.time.map({"Baseline": 0, "Week6": 1, "Week12": 2}).to_numpy()
d["y"] = (30 + subject_effect[d.id.to_numpy()] + 1.2*t +
          2*(d.group.to_numpy() == "Treatment")*t + rng.normal(0,2,len(d)))

import statsmodels.formula.api as smf
fit=smf.mixedlm("y ~ C(group)*C(time)",data=d,groups=d["id"]).fit(reml=False)
print(fit.summary())
