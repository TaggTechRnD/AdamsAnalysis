Friedman Test

Statistical method reference guide

Overview and appropriate use

Purpose

Friedman test compares ranked responses across three or more related conditions or timepoints.

Example research questions

Does perceived exertion change across four activities undertaken by the same participants?

Design requirements

Blocked or repeated ordinal or quantitative observations, commonly complete sets of measurements for each block.

Strengths

Accounts for within-person blocking without assuming a normal outcome.

Limitations

Limited for missing or irregular repeats and does not identify specific differing pairs on its own.

When not to use it

Do not apply to independent groups or infer the size of a mean difference from its rank statistic.

Illustrative research scenario (hypothetical)

Compare three repeated clinical symptom scores within the same patients.

Mathematical foundation

Mathematical foundation

rank test statistic

\(Q=\frac{12}{nk(k+1)}\sum_{j=1}^{k}R_{\cdot j}^2-3n(k+1)\)
View LaTeX source
Q=\frac{12}{nk(k+1)}\sum_{j=1}^{k}R_{\cdot j}^2-3n(k+1)

Symbols

n: complete blocks or participants; k: within-block conditions; R_.j: sum of within-block ranks for condition j.

Explanation

Compares repeated conditions by ranking measurements within each participant or block.

Important scope limitation

Requires matched complete blocks in its classical form; ties require a correction.

Assumptions and diagnostics

Assumptions and conditions

Measurements form valid matched blocks or repeated units, with consistent condition ordering and valid within-block comparisons.

Diagnostics to perform

Check that each block has required observations or documented handling of missingness; inspect per-block ranks, ties, and condition order.

Consequences of violations

Incomplete blocks may be dropped or require a different procedure; broken block matching or dependence across blocks invalidates standard inference.

Diagnostic caveats

Friedman is an omnibus rank test and does not identify which pairs of conditions differ without follow-up comparisons.

Understanding the results

Primary outputs

Friedman chi-square statistic, degrees of freedom, block count and condition rank summaries.

Inference and tests

Tests whether repeated-condition ranks are exchangeable across matched blocks; post-hoc comparisons require correction.

Effect sizes and intervals

Kendall W describes concordance/effect magnitude on a bounded 0–1 scale; report uncertainty if available.

Model fit and performance

Check complete matched blocks and valid within-block ranking; no general model fit index.

Interpreting results

Larger Kendall W reflects more consistently ordered conditions across blocks.

Common mistakes

This is not an analysis of arbitrary unbalanced longitudinal trajectories and does not identify which pairs differ by itself.

Example report wording (placeholder values)

Friedman χ²([df]) = [stat], p = [p]; Kendall W = [W]; matched blocks = [n].

R tutorial

Learning goal

Compare repeated rank outcomes across three visits.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

stats

R example

set.seed(2026)
n <- 90
d <- expand.grid(id = seq_len(n), time = factor(c("Baseline","Week6","Week12"),
                 levels=c("Baseline","Week6","Week12")))
d$group <- factor(ifelse(d$id <= n/2, "Control", "Treatment"))
subject_effect <- rnorm(n, sd = 3)
d$y <- 30 + subject_effect[d$id] + 1.2*(as.integer(d$time)-1) +
  2*(d$group == "Treatment")*(as.integer(d$time)-1) + rnorm(nrow(d), sd=2)

wide<-reshape(d[,c("id","time","y")],idvar="id",timevar="time",direction="wide")
print(friedman.test(as.matrix(wide[,grep("^y[.]",names(wide))])))

Output to inspect

Friedman chi-square statistic and p-value.

Limitations and checks

Requires complete blocks in this example; follow up significant omnibus result with appropriate comparisons.

Python tutorial

Learning goal

Compare repeated rank outcomes across three visits.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
d = pd.MultiIndex.from_product([range(n), ["Baseline","Week6","Week12"]],
                               names=["id","time"]).to_frame(index=False)
d["group"] = np.where(d.id < n // 2, "Control", "Treatment")
subject_effect = rng.normal(0, 3, n)
t = d.time.map({"Baseline": 0, "Week6": 1, "Week12": 2}).to_numpy()
d["y"] = (30 + subject_effect[d.id.to_numpy()] + 1.2*t +
          2*(d.group.to_numpy() == "Treatment")*t + rng.normal(0,2,len(d)))

from scipy import stats
wide=d.pivot(index="id",columns="time",values="y")
print(stats.friedmanchisquare(*[wide[c] for c in ["Baseline","Week6","Week12"]]))
