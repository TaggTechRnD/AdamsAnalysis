Fisher's Exact Test

Statistical method reference guide

Overview and appropriate use

Purpose

Fisher's exact test evaluates association in a contingency table using an exact conditional reference distribution rather than a large-sample chi-square approximation.

Example research questions

Is a rare adverse event associated with treatment group in a small trial?

Design requirements

Categorical count data, often a small or sparse two-by-two table; appropriate sampling and independence assumptions.

Strengths

Valid significance testing in sparse tables where asymptotic chi-square tests may be unreliable.

Limitations

Can be conservative and computationally costly for larger tables; does not establish a causal effect.

When not to use it

Do not substitute it for methods that handle matched or clustered observations when those dependencies matter.

Illustrative research scenario (hypothetical)

Compare rare treatment complications across two small independent groups.

Mathematical foundation

Mathematical foundation

exact probability

\(P(A=a\mid\mathrm{margins})=\frac{\binom{r_1}{a}\binom{r_2}{c_1-a}}{\binom{n}{c_1}}\)
View LaTeX source
P(A=a\mid\mathrm{margins})=\frac{\binom{r_1}{a}\binom{r_2}{c_1-a}}{\binom{n}{c_1}}

Symbols

a: upper-left cell count in a 2×2 table; r1,r2: row totals; c1: first-column total; n: grand total.

Explanation

Provides the conditional probability of each possible 2×2 table given fixed margins.

Important scope limitation

Two-sided p-values require a stated convention; inference relies on the data-generating and sampling design.

Assumptions and diagnostics

Assumptions and conditions

Cross-tabulated counts come from independent observational units and a sampling scheme compatible with the exact conditional test.

Diagnostics to perform

Verify independent units, table orientation and fixed-margin assumptions, inspect zero cells and data collection design.

Consequences of violations

Nonindependent observations or selection mechanisms can invalidate the inferential interpretation despite the exact p-value calculation.

Diagnostic caveats

Fisher exact test does not require large expected counts; exactness refers to its stated sampling model, not absence of bias.

Understanding the results

Primary outputs

2×2 or larger contingency table, Fisher exact p-value, and conditional odds ratio where applicable.

Inference and tests

Exact conditional test evaluates independence for the chosen table, particularly useful with sparse counts.

Effect sizes and intervals

For a 2×2 table, report odds ratio and its exact/appropriate interval; describe the estimation method.

Model fit and performance

Check table construction and independence of units; model fit indices do not apply.

Interpreting results

An odds ratio above 1 indicates higher odds in one category/group relative to the specified reference.

Common mistakes

An odds ratio is not a risk ratio, and an exact p-value does not eliminate selection bias or confounding.

Example report wording (placeholder values)

Fisher exact p = [p]; odds ratio = [OR] (95% CI [lower], [upper]); table = [counts].

R tutorial

Learning goal

Test association in a two-by-two categorical table.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

stats

R example

set.seed(2026)
n <- 280
x <- rnorm(n)
treatment <- rbinom(n, 1, 0.5)
p <- plogis(-0.5 + 0.8*x - 0.7*treatment)
y <- rbinom(n, 1, p)
d <- data.frame(y, x, treatment)

ct<-table(d$treatment,d$y)
print(fisher.test(ct))

Output to inspect

Odds ratio and exact p-value.

Limitations and checks

For 2×2 tables; an odds ratio is not the same as a risk ratio.

Python tutorial

Learning goal

Test association in a two-by-two categorical table.

Simulated data

280 independent binary outcomes associated with a continuous risk factor and binary treatment.

Packages

numpy, pandas, scipy

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 280
x = rng.normal(size=n)
treatment = rng.binomial(1, .5, n)
p = 1 / (1 + np.exp(-(-.5 + .8*x - .7*treatment)))
y = rng.binomial(1, p)
d = pd.DataFrame({"y": y,"x": x,"treatment":treatment})

from scipy import stats
ct=pd.crosstab(d.treatment,d.y).to_numpy()
print(stats.fisher_exact(ct))
