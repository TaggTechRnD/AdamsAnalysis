Artificial Neural Network

Statistical method reference guide

Overview and appropriate use

Purpose

Artificial neural networks learn layered transformations of inputs to predict outcomes or complex patterns.

Example research questions

Can multivariate wearable measurements predict episodes of clinical deterioration?

Design requirements

Defined prediction task, sufficient representative training data, justified architecture, tuning, and held-out evaluation.

Strengths

Highly flexible for complex nonlinear patterns and high-dimensional inputs.

Limitations

Data hungry and difficult to interpret; vulnerable to overfitting, dataset shift, and leakage.

When not to use it

Do not deploy a high-accuracy model without checking generalizability, calibration, and fairness in the target setting.

Illustrative research scenario (hypothetical)

Predict deterioration from multiple streams of wearable sensor measurements.

\boldsymbol{a}^{(\ell)}=\sigma\!\left(W^{(\ell)}\boldsymbol{a}^{(\ell-1)}+\boldsymbol{b}^{(\ell)}\right)

Symbols

a^(ℓ): layer activation; W: weights; b: biases; σ: activation function.

Explanation

A neural network repeatedly transforms inputs through learned weighted nonlinear layers.

Important scope limitation

This is a generic feed-forward layer, not a complete training algorithm or architecture.

Assumptions and diagnostics

Assumptions and conditions

Network architecture and capacity are commensurate with data volume; preprocessing, tuning and final validation are separated to avoid leakage.

Diagnostics to perform

Inspect training and validation loss curves, overfitting gaps, hyperparameter sensitivity, calibration, subgroup errors and performance on a true holdout.

Consequences of violations

Excessive network capacity overfits and performs poorly on new samples; distribution drift undermines generalization.

Diagnostic caveats

Training convergence does not establish stable performance, interpretability or causal identification.

Understanding the results

Primary outputs

Predicted classes/probabilities or continuous outcomes, fitted network specification and training history.

Inference and tests

Neural networks lack default classical coefficient p-values; uncertainty requires deliberate calibration or resampling.

Effect sizes and intervals

Report meaningful predicted contrasts and prediction intervals or calibrated probabilities when available.

Model fit and performance

Held-out loss, calibration, AUC or RMSE; examine training/validation gap and robustness to initialization.

Interpreting results

A model can accurately capture complex patterns without yielding a transparent statistical effect for any one feature.

Common mistakes

Attribution scores are model-explanation tools, not proof of causal importance; large training accuracy can reflect overfitting.

Example report wording (placeholder values)

Network [architecture] achieved held-out [metric] = [value] under [validation scheme].

R tutorial

Learning goal

Classify binary outcomes using a small feed-forward neural network.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

nnet

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

fit<-nnet::nnet(y~x1+x2+x3,data=train,size=4,decay=.01,
                maxit=300,trace=FALSE)
p<-predict(fit,test,type="class")
print(table(truth=test$y,predicted=p))

Output to inspect

Holdout accuracy and convergence diagnostics.

Limitations and checks

Training is stochastic and sensitive to scaling, early stopping and model capacity.

Python tutorial

Learning goal

Classify binary outcomes using a small feed-forward neural network.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.neural_network import MLPClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score
cols=["x1","x2","x3"]
fit=make_pipeline(StandardScaler(),MLPClassifier(hidden_layer_sizes=(4,),
                 max_iter=1000,random_state=2026,early_stopping=True)).fit(train[cols],train.y)
print("Test accuracy:",accuracy_score(test.y,fit.predict(test[cols])))
