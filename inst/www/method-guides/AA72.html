Isolation Forest

Statistical method reference guide

Overview and appropriate use

Purpose

Isolation forest detects unusual observations by measuring how easily randomly partitioning trees isolate them.

Example research questions

Which health-system records have unusual combinations of utilization metrics?

Design requirements

Comparable features, enough data to characterize typical observations, and an operational definition for reviewing anomalies.

Strengths

Scales well to high-dimensional anomaly screening without requiring labeled anomalies.

Limitations

An anomaly score does not establish an error, fraud, or clinical event and may reflect legitimate rare cases.

When not to use it

Do not automatically delete flagged observations or treat algorithmic anomalies as confirmed data-quality failures.

Illustrative research scenario (hypothetical)

Flag unusual provider-level daily activity patterns for human QA review.

Mathematical foundation

Mathematical foundation

anomaly score

\(s(x,n)=2^{-E[h(x)]/c(n)}\)
View LaTeX source
s(x,n)=2^{-E[h(x)]/c(n)}

Symbols

h(x): path length to isolate point x; c(n): expected reference path length at sample size n.

Explanation

Isolation forest assigns higher anomaly scores to cases isolated by shorter random partition paths.

Important scope limitation

Scores depend on forest construction and sampling; labels need a separately chosen threshold.

Assumptions and diagnostics

Assumptions and conditions

Anomalies are comparatively rare and distinguishable by isolation in the chosen feature space; reference training sample reflects intended baseline population.

Diagnostics to perform

Check feature quality, contamination assumptions, anomalous-score stability, validation against known cases if available, and subgroup false-positive rates.

Consequences of violations

Nonrepresentative reference data or shifting populations cause high false alerts; correlated feature artifacts can dominate scores.

Diagnostic caveats

An anomaly score flags unusual records, not confirmed fraud, illness, or data error.

Understanding the results

Primary outputs

Anomaly scores, flagged records and contamination/threshold choice.

Inference and tests

Isolation Forest does not intrinsically yield p-values for anomalous observations.

Effect sizes and intervals

Report proportions flagged, score distributions and precision/recall against independently labeled anomalies if available.

Model fit and performance

Evaluate stability and external validation; false-positive rate depends on labeling and threshold.

Interpreting results

An unusually high anomaly score means a case is isolated quickly relative to the fitted reference distribution.

Common mistakes

A flagged observation is not necessarily erroneous, fraudulent or clinically abnormal.

Example report wording (placeholder values)

Isolation Forest flagged [n] of [N] records ([percent]%) at threshold [rule]; validated precision = [value] if known.

R tutorial

Learning goal

Assign anomaly scores by random tree isolation.

Simulated data

180 unlabeled observations from three well-separated feature clusters.

Packages

isotree

R example

set.seed(2026)
X <- rbind(matrix(rnorm(120, mean=-2, sd=.5), ncol=2),
           matrix(rnorm(120, mean=2, sd=.5), ncol=2),
           cbind(rnorm(60,mean=2,sd=.5),rnorm(60,mean=-2,sd=.5)))
colnames(X)<-c("feature1","feature2")

fit<-isotree::isolation.forest(as.data.frame(X),ntrees=150,seed=2026)
score<-predict(fit,as.data.frame(X),type="score")
print(head(sort(score,decreasing=TRUE),10))

Output to inspect

Highest-scoring unusual records; inspect rather than automatically delete.

Limitations and checks

Scoring conventions differ by library; anomalies are not necessarily data errors.

Python tutorial

Learning goal

Assign anomaly scores by random tree isolation.

Simulated data

180 unlabeled observations from three well-separated feature clusters.

Packages

numpy, scikit-learn

Python example

import numpy as np
rng=np.random.default_rng(2026)
X=np.vstack([rng.normal(-2,.5,(60,2)),rng.normal(2,.5,(60,2)),
             np.column_stack([rng.normal(2,.5,60),rng.normal(-2,.5,60)])])

from sklearn.ensemble import IsolationForest
fit=IsolationForest(n_estimators=150,random_state=2026,contamination=.05).fit(X)
score=-fit.score_samples(X) # larger scores mean more anomalous
print("Most anomalous indices:",np.argsort(score)[-10:][::-1])
