Decision Tree

Statistical method reference guide

Overview and appropriate use

Purpose

Decision trees recursively partition predictor space to produce understandable classification or regression rules.

Example research questions

Which combinations of symptoms and demographics best predict a screening result?

Design requirements

Labeled outcome and suitable predictors; adequate training data and a separate evaluation strategy.

Strengths

Easy to visualize and handles nonlinear thresholds and interactions.

Limitations

Individual trees can be unstable and may overfit without pruning or tuning.

When not to use it

Do not assess performance solely on the training data or interpret splitting rules as causal effects.

Illustrative research scenario (hypothetical)

Build a tree to classify elevated fall risk from mobility and demographic measures.

Mathematical foundation

Mathematical foundation

splitting criterion

\(G(t)=1-\sum_{k=1}^{K}p_{k\mid t}^2\)
View LaTeX source
G(t)=1-\sum_{k=1}^{K}p_{k\mid t}^2

Symbols

G(t): Gini impurity at node t; p_k|t: proportion of class k at node t.

Explanation

A classification tree chooses splits that reduce a criterion such as impurity.

Important scope limitation

This is one common classification-tree criterion; regression trees often minimize squared error instead.

Assumptions and diagnostics

Assumptions and conditions

Train and evaluation records reflect deployment conditions; predictors exclude information unavailable at prediction time; tree complexity is tuned without test-set leakage.

Diagnostics to perform

Check data leakage and duplicates, use held-out or cross-validated error, compare training versus validation performance, inspect class-specific metrics and subgroup performance.

Consequences of violations

Leakage or untuned deep trees yields exaggerated accuracy and poor generalization; imbalance can make accuracy misleading.

Diagnostic caveats

Decision trees make few distributional assumptions, but predictive validity still depends on sampling and validation design.

Understanding the results

Primary outputs

Tree split rules, terminal-node predicted outcomes and variable-importance measures where available.

Inference and tests

A standard prediction tree does not inherently test hypotheses with coefficient p-values.

Effect sizes and intervals

Use predictive differences/probabilities and uncertainty from appropriate validation/resampling; importance is not a causal effect.

Model fit and performance

Report held-out RMSE/MAE for regression or AUC, calibration and confusion-matrix metrics for classification.

Interpreting results

A branch describes the model’s prediction for observations meeting a sequence of conditions.

Common mistakes

In-sample accuracy can be optimistic; split thresholds and importance are unstable and should not be treated as causal.

Example report wording (placeholder values)

Held-out [metric] = [value]; tree depth = [depth]; key predictive splits = [variables].

R tutorial

Learning goal

Fit an interpretable classification tree and evaluate it on holdout data.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

rpart

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

fit<-rpart::rpart(y~x1+x2+x3,data=train,method="class")
p<-predict(fit,newdata=test,type="class")
print(table(truth=test$y,predicted=p))

Output to inspect

Confusion matrix or test accuracy and tree splits.

Limitations and checks

A single tree is unstable; avoid evaluating it only on the training set.

Python tutorial

Learning goal

Fit an interpretable classification tree and evaluate it on holdout data.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score
fit=DecisionTreeClassifier(max_depth=3,random_state=2026).fit(train[["x1","x2","x3"]],train.y)
p=fit.predict(test[["x1","x2","x3"]])
print("Test accuracy:",accuracy_score(test.y,p))
