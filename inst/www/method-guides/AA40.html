Polynomial Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Polynomial regression augments a regression model with powers of a predictor to represent smooth curvature.

Example research questions

Does the association between age and lung function bend across adulthood?

Design requirements

An outcome and regression family suited to the question, continuous predictors, and enough support across the predictor range for the chosen degree.

Strengths

Flexible within familiar regression models and permits formal checks of curvature.

Limitations

High-degree polynomials may oscillate and extrapolate poorly; individual terms are difficult to interpret.

When not to use it

Do not select high polynomial degrees solely to maximize in-sample fit or extrapolate far beyond observed data.

Illustrative research scenario (hypothetical)

Model a curved association between age and measured lung capacity.

Mathematical foundation

Mathematical foundation

linear model

\(Y_i=\beta_0+\beta_1x_i+\beta_2x_i^2+\cdots+\beta_px_i^p+\varepsilon_i\)
View LaTeX source
Y_i=\beta_0+\beta_1x_i+\beta_2x_i^2+\cdots+\beta_px_i^p+\varepsilon_i

Symbols

p: polynomial degree; β_j: coefficients; x: predictor.

Explanation

Allows a curved conditional mean while remaining linear in model coefficients.

Important scope limitation

High-degree polynomials may overfit or extrapolate poorly.

Assumptions and diagnostics

Assumptions and conditions

Continuous predictor and outcome support an adequately specified polynomial mean relation; errors and sampling structure support the chosen regression inference.

Diagnostics to perform

Plot outcome against predictor, residual patterns, leverage at range extremes, compare degrees using validation or nested tests, and inspect overfitting.

Consequences of violations

High-degree fits can oscillate and extrapolate wildly; misspecified curvature and outliers bias interpretation.

Diagnostic caveats

Polynomial coefficients depend on scaling and centering; predictions beyond observed predictor range are especially fragile.

Understanding the results

Primary outputs

Linear and polynomial-term coefficients, fitted curves and predicted means.

Inference and tests

Individual term tests and joint polynomial comparisons may assess curvature, but depend on model specification.

Effect sizes and intervals

Report predicted outcome contrasts or marginal slopes at meaningful predictor values with intervals.

Model fit and performance

Adjusted R², residual plots, and cross-validated prediction error; compare polynomials at same dataset/design.

Interpreting results

A significant quadratic term suggests modeled curvature, but the practical pattern is best shown with fitted predictions.

Common mistakes

A polynomial coefficient alone is not a constant change per X unit, and high-degree fits can extrapolate wildly.

Example report wording (placeholder values)

Quadratic term β₂ = [value] (p = [p]); predicted Y at X = [x1] versus [x2] differed by [diff] (95% CI [limits]).

R tutorial

Learning goal

Fit quadratic association allowing curvature.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

stats

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

fit<-lm(y~poly(x,2,raw=TRUE),data=d)
print(summary(fit))

Output to inspect

Linear and squared coefficients and fitted curve.

Limitations and checks

Polynomial terms describe shape; extrapolation can be unstable.

Python tutorial

Learning goal

Fit quadratic association allowing curvature.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.formula.api as smf
fit=smf.ols("y ~ x + I(x**2)",data=d).fit()
print(fit.summary())
