Naive Bayes

Statistical method reference guide

Overview and appropriate use

Purpose

Naive Bayes applies Bayes' rule to classify outcomes using a model that assumes predictor independence conditional on class.

Example research questions

Can a lightweight model classify symptoms into likely diagnostic categories?

Design requirements

Labeled classes, relevant feature representations, suitable likelihood models, and validation of predictive calibration.

Strengths

Fast to train and effective for some high-dimensional or sparse classification tasks.

Limitations

Conditional independence is often unrealistic, and predicted probabilities can be poorly calibrated.

When not to use it

Do not interpret class probabilities as reliable clinical risks without validation and calibration.

Illustrative research scenario (hypothetical)

Classify text-based symptom reports into triage categories.

Mathematical foundation

Mathematical foundation

probabilistic classifier

\(P(C=k\mid x_1,\ldots,x_p)\propto P(C=k)\prod_{j=1}^{p}P(x_j\mid C=k)\)
View LaTeX source
P(C=k\mid x_1,\ldots,x_p)\propto P(C=k)\prod_{j=1}^{p}P(x_j\mid C=k)

Symbols

C: class; x_j: feature; P(C): prior class probability.

Explanation

Naive Bayes combines class priors with feature likelihoods to classify new cases.

Important scope limitation

Assumes conditional independence of features given class, often only approximately true.

Assumptions and diagnostics

Assumptions and conditions

Class priors and feature likelihood models are plausible; naive Bayes approximates conditional independence of features within each class.

Diagnostics to perform

Review feature dependence within classes, predicted versus observed probabilities, prior prevalence and held-out class-wise performance.

Consequences of violations

Strong within-class dependence or misspecified likelihoods may yield poorly calibrated probabilities.

Diagnostic caveats

Conditional independence is an approximation, not a guarantee; useful classification can occur despite violation.

Understanding the results

Primary outputs

Predicted class probabilities, estimated class priors and conditional feature likelihoods.

Inference and tests

No inherent coefficient-significance tests; validation quantifies predictive utility and probability calibration.

Effect sizes and intervals

Compare calibrated predicted risks and classification metrics, not causal variable-effect estimates.

Model fit and performance

Held-out log loss, Brier score, calibration and AUC/accuracy; inspect sensitivity to violated conditional independence.

Interpreting results

The algorithm combines class priors and feature evidence under conditional-independence assumptions.

Common mistakes

Strong classification accuracy does not imply the feature-independence assumption holds or estimated probabilities are calibrated.

Example report wording (placeholder values)

Naive Bayes held-out AUC = [AUC], log loss = [loss], and calibration assessment = [result].

R tutorial

Learning goal

Use a conditional-independence classification baseline.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

e1071

R example

set.seed(2026)
n <- 300
x1 <- rnorm(n); x2 <- rnorm(n); x3 <- rnorm(n)
p <- plogis(-.2 + 1.2*x1 - .8*x2 + .5*x3)
y <- factor(rbinom(n,1,p),levels=c(0,1),labels=c("No","Yes"))
d <- data.frame(x1,x2,x3,y)
idx <- sample(seq_len(n), size=round(.7*n))
train <- d[idx,]; test <- d[-idx,]

fit<-e1071::naiveBayes(y~x1+x2+x3,data=train)
p<-predict(fit,test)
print(table(truth=test$y,predicted=p))

Output to inspect

Holdout confusion matrix.

Limitations and checks

Conditional independence is usually approximate; poor calibration is possible.

Python tutorial

Learning goal

Use a conditional-independence classification baseline.

Simulated data

300 simulated patient records with three predictors and a binary classification outcome; 70/30 split.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
rng = np.random.default_rng(2026)
n = 300
x1=rng.normal(size=n); x2=rng.normal(size=n); x3=rng.normal(size=n)
p=1/(1+np.exp(-(-.2+1.2*x1-.8*x2+.5*x3)))
y=rng.binomial(1,p)
d=pd.DataFrame({"x1":x1,"x2":x2,"x3":x3,"y":y})
train,test=train_test_split(d, test_size=.3, random_state=2026, stratify=d.y)

from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import confusion_matrix
cols=["x1","x2","x3"]
fit=GaussianNB().fit(train[cols],train.y)
print(confusion_matrix(test.y,fit.predict(test[cols])))
