K-Means Clustering

Statistical method reference guide

Overview and appropriate use

Purpose

K-means clustering partitions observations into a chosen number of groups by minimizing within-cluster squared distances to centroids.

Example research questions

Can participants be grouped into common profiles of activity and fitness measurements?

Design requirements

Appropriate numeric features, meaningful scaling, a chosen cluster count, and a distance geometry consistent with compact clusters.

Strengths

Fast, scalable exploratory summary of cluster centroids and assignments.

Limitations

Sensitive to scaling, outliers, initialization, and non-spherical groups; the number of clusters must be justified.

When not to use it

Do not treat clusters as validated disease subtypes or use raw features with incompatible scales without examination.

Illustrative research scenario (hypothetical)

Cluster adults by standardized fitness and activity measurements.

Mathematical foundation

Mathematical foundation

clustering objective

\(\min_{C_1,\ldots,C_K}\sum_{k=1}^{K}\sum_{i\in C_k}\lVert\boldsymbol{x}_i-\boldsymbol{\mu}_k\rVert^2\)
View LaTeX source
\min_{C_1,\ldots,C_K}\sum_{k=1}^{K}\sum_{i\in C_k}\lVert\boldsymbol{x}_i-\boldsymbol{\mu}_k\rVert^2

Symbols

C_k: cluster k; μ_k: cluster centroid; K: chosen number of clusters.

Explanation

K-means partitions observations to minimize within-cluster squared distances to centroids.

Important scope limitation

Sensitive to scaling, starting positions and outliers; results need not reflect natural groupings.

Assumptions and diagnostics

Assumptions and conditions

Numeric features have meaningful distance and scaling; approximately compact cluster structure is suitable for Euclidean centroid partitions.

Diagnostics to perform

Inspect feature scales/outliers, cluster sizes, inertia/elbow, silhouette, multiple random starts and stability under resampling.

Consequences of violations

Poor scaling and outliers distort centroids; elongated or unequal-density clusters can be misrepresented.

Diagnostic caveats

Silhouette or elbow plots do not prove natural clusters exist. The chosen k is an analytic decision.

Understanding the results

Primary outputs

Cluster assignments, centroids, within-cluster sum of squares and selected k.

Inference and tests

Ordinary k-means has no automatic p-values or confidence intervals for clusters.

Effect sizes and intervals

Report cluster sizes, centroid differences and stability rather than causal effect sizes.

Model fit and performance

Within-cluster sum of squares, silhouette score and stability are descriptive selection criteria; no universal fit threshold.

Interpreting results

Clusters group observations relatively close under the specified scaled distance and chosen k.

Common mistakes

Cluster membership is not evidence of true natural subpopulations; changing scaling or k can substantially alter results.

Example report wording (placeholder values)

k-means k = [k]; cluster sizes = [sizes]; mean silhouette = [score]; stability = [assessment].

R tutorial

Learning goal

Partition unlabeled cases into three compact clusters.

Simulated data

180 unlabeled observations from three well-separated feature clusters.

Packages

stats

R example

set.seed(2026)
X <- rbind(matrix(rnorm(120, mean=-2, sd=.5), ncol=2),
           matrix(rnorm(120, mean=2, sd=.5), ncol=2),
           cbind(rnorm(60,mean=2,sd=.5),rnorm(60,mean=-2,sd=.5)))
colnames(X)<-c("feature1","feature2")

fit<-kmeans(scale(X),centers=3,nstart=20)
print(table(fit$cluster))
print(fit$tot.withinss)

Output to inspect

Cluster sizes, within-cluster sum of squares.

Limitations and checks

Number of clusters is specified, not inferred; no inherent p-value.

Python tutorial

Learning goal

Partition unlabeled cases into three compact clusters.

Simulated data

180 unlabeled observations from three well-separated feature clusters.

Packages

numpy, scikit-learn

Python example

import numpy as np
rng=np.random.default_rng(2026)
X=np.vstack([rng.normal(-2,.5,(60,2)),rng.normal(2,.5,(60,2)),
             np.column_stack([rng.normal(2,.5,60),rng.normal(-2,.5,60)])])

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
fit=KMeans(n_clusters=3,n_init=20,random_state=2026).fit(StandardScaler().fit_transform(X))
print("Cluster sizes:",np.bincount(fit.labels_))
print("Inertia:",fit.inertia_)
