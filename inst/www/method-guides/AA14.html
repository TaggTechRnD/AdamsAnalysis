Mixed-Design ANOVA

Statistical method reference guide

Overview and appropriate use

Purpose

Mixed-design ANOVA compares a continuous outcome across independent groups measured repeatedly over time or conditions, including a group-by-time interaction.

Example research questions

Does an exercise intervention improve fitness more than a control group?; Do treatment groups exhibit different changes over repeated visits?

Design requirements

Continuous outcome; at least one between-subject grouping factor and one within-subject repeated factor; independent participants across groups.

Strengths

Tests between-group differences, within-person change, and group-by-time patterns in a single model; well suited to simple balanced designs.

Limitations

Classical implementations handle missing or irregular visits poorly; sphericity matters for within-subject factors with more than two levels.

When not to use it

Do not treat incomplete repeated measures as independent or infer causality from an observational group-by-time interaction alone.

Illustrative research scenario (hypothetical)

In a trial of 88 adults randomized to exercise or control, assess whether fitness measured at baseline, six weeks, and twelve weeks changes differently by group.

Mathematical foundation

Y_{igt}=\mu+\alpha_g+\tau_t+(\alpha\tau)_{gt}+b_{i(g)}+\varepsilon_{igt}

Symbols

g: independent group; t: repeated timepoint; i: subject nested in group; α: group effect; τ: time effect; (ατ): interaction; b: subject effect.

Explanation

The group-by-time interaction tests whether groups change differently across repeated measurements.

Important scope limitation

The model alone does not prove causality; assignment and causal design assumptions are separate. Classical ANOVA requires appropriate covariance assumptions.

Assumptions and diagnostics

Assumptions and conditions

Participants are independent between groups but repeatedly measured within participant. Continuous outcome, meaningful group-by-time structure, suitable residual model and within-person covariance are required.

Diagnostics to perform

Verify participant IDs, group allocation, missing visits, subject trajectories and residual Q-Q plots; assess group-specific residual spreads. Check sphericity/epsilon only for at least three within-person levels.

Consequences of violations

Ignoring unequal residual spread, correlated measures or informative missingness can misstate the group-by-time effect. Sphericity violations affect uncorrected repeated-measures F tests.

Diagnostic caveats

With two timepoints, sphericity is automatic. A significant interaction is not by itself proof of causality without an appropriate study design.

Understanding the results

Primary outputs

F tests for group, time and group × time interaction; cell means and estimated marginal means.

Inference and tests

The interaction F test evaluates whether mean time profiles differ between groups, with degrees-of-freedom correction where applicable.

Effect sizes and intervals

Report the group × time contrast (e.g., difference in change) with a confidence interval and an appropriate ANOVA effect size.

Model fit and performance

Inspect independence of groups, repeated-measure covariance and residuals; with two timepoints, sphericity needs no test.

Interpreting results

For two groups and two occasions, a positive difference-in-change means one group improved more on average than the other.

Common mistakes

A significant interaction is not automatically causal outside valid experimental or causal-identification assumptions.

Example report wording (placeholder values)

R tutorial

Learning goal

Evaluate whether treatment and control groups change differently over visits.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

afex

R example

set.seed(2026)
n <- 90
d <- expand.grid(id = seq_len(n), time = factor(c("Baseline","Week6","Week12"),
                 levels=c("Baseline","Week6","Week12")))
d$group <- factor(ifelse(d$id <= n/2, "Control", "Treatment"))
subject_effect <- rnorm(n, sd = 3)
d$y <- 30 + subject_effect[d$id] + 1.2*(as.integer(d$time)-1) +
  2*(d$group == "Treatment")*(as.integer(d$time)-1) + rnorm(nrow(d), sd=2)

# Install optional dependency beforehand: install.packages("afex")
fit<-afex::aov_ez(id="id",dv="y",data=d,between="group",within="time")
print(fit)

Output to inspect

Group × time interaction, F statistic, partial eta-squared; check corrections.

Limitations and checks

Requires subject IDs, independent groups, complete/balanced visits for this example; a significant interaction alone is not proof of causality.

Python tutorial

Learning goal

Evaluate whether treatment and control groups change differently over visits.

Simulated data

90 participants randomized to two groups, each measured at three visits (long format).

Packages

numpy, pandas, pingouin

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 90
d = pd.MultiIndex.from_product([range(n), ["Baseline","Week6","Week12"]],
                               names=["id","time"]).to_frame(index=False)
d["group"] = np.where(d.id < n // 2, "Control", "Treatment")
subject_effect = rng.normal(0, 3, n)
t = d.time.map({"Baseline": 0, "Week6": 1, "Week12": 2}).to_numpy()
d["y"] = (30 + subject_effect[d.id.to_numpy()] + 1.2*t +
          2*(d.group.to_numpy() == "Treatment")*t + rng.normal(0,2,len(d)))

# Install optional dependency beforehand: pip install pingouin
import pingouin as pg
result=pg.mixed_anova(data=d,dv="y",within="time",between="group",subject="id")
print(result)
