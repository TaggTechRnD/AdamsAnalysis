Principal Component Analysis (PCA)

Statistical method reference guide

Overview and appropriate use

Purpose

Principal component analysis constructs orthogonal linear combinations of measured numeric variables to summarize major patterns of variation.

Example research questions

Can correlated activity and fitness measures be summarized using fewer scores?

Design requirements

Multiple quantitative variables measured on comparable cases; consider scaling, missingness, and whether linear components are meaningful.

Strengths

Reduces dimension and can reveal dominant axes of variation before later analysis.

Limitations

Components maximize variance rather than predict outcomes or identify causal latent constructs; loadings are sample dependent.

When not to use it

Do not interpret components automatically as validated psychological constructs or as evidence of causal structure.

Illustrative research scenario (hypothetical)

Combine several highly correlated physical-fitness measurements into summary component scores.

Mathematical foundation

Mathematical foundation

decomposition / optimization

\(\max_{\lVert\boldsymbol{w}\rVert=1}\boldsymbol{w}^\top S\boldsymbol{w}\)
View LaTeX source
\max_{\lVert\boldsymbol{w}\rVert=1}\boldsymbol{w}^\top S\boldsymbol{w}

Symbols

S: sample covariance or correlation matrix; w: principal-component loading direction.

Explanation

The first principal component is the direction of maximum sample variance; later components are orthogonal.

Important scope limitation

Components describe variance, not necessarily meaningful latent causes; scale choices strongly affect results.

Assumptions and diagnostics

Assumptions and conditions

Multiple numerical variables contain meaningful shared variation; variable scaling is consistent with the analytic goal. Principal components are descriptive directions of variance.

Diagnostics to perform

Examine variable correlations, SDs and units, missingness, outliers, scree plot, explained variance, and loading stability under resampling.

Consequences of violations

Poor scaling or a few extremes can dominate components; unstable loadings and weak shared structure undermine interpretation.

Diagnostic caveats

PCA does not assume a latent-variable measurement model, and high explained variance does not prove construct validity.

Understanding the results

Primary outputs

Principal-component eigenvalues, component loadings/scores and proportion of total variance explained.

Inference and tests

Ordinary PCA has no intrinsic coefficient p-values; resampling/permutation assesses component stability if required.

Effect sizes and intervals

Explained-variance percentages and loadings show data compression, not causal effect size; uncertainty is not default.

Model fit and performance

Scree plot, reconstruction error and stability; no standard inferential model-fit p-value.

Interpreting results

A first component explaining 40% means it captures 40% of variation under the chosen scaling of included variables.

Common mistakes

High loadings do not establish a validated latent construct; PCA results depend on variable scaling.

Example report wording (placeholder values)

PC1 explained [percent]% variance; highest absolute loadings were [variables] (scaling: [method]).

R tutorial

Learning goal

Find orthogonal directions explaining variability in standardized indicators.

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

stats

R example

set.seed(2026)
n <- 240
f1 <- rnorm(n); f2 <- 0.3*f1 + rnorm(n)
d <- data.frame(
  a1=0.9*f1+rnorm(n,sd=.5), a2=0.8*f1+rnorm(n,sd=.6),
  a3=0.7*f1+rnorm(n,sd=.6), b1=0.9*f2+rnorm(n,sd=.5),
  b2=0.8*f2+rnorm(n,sd=.6), b3=0.7*f2+rnorm(n,sd=.6))

fit<-prcomp(d,center=TRUE,scale.=TRUE)
print(summary(fit))
print(fit$rotation)

Output to inspect

Explained-variance ratios and loadings.

Limitations and checks

Component directions are descriptive; PCA does not prove latent constructs.

Python tutorial

Simulated data

Six observed survey items generated from two correlated latent factors.

Packages

numpy, pandas, scikit-learn

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 240
f1 = rng.normal(size=n); f2 = .3*f1 + rng.normal(size=n)
d = pd.DataFrame({
 "a1":.9*f1+rng.normal(0,.5,n), "a2":.8*f1+rng.normal(0,.6,n),
 "a3":.7*f1+rng.normal(0,.6,n), "b1":.9*f2+rng.normal(0,.5,n),
 "b2":.8*f2+rng.normal(0,.6,n), "b3":.7*f2+rng.normal(0,.6,n)})

from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
z=StandardScaler().fit_transform(d)
fit=PCA().fit(z)
print("Variance explained:",fit.explained_variance_ratio_)
print("Loadings:\n",fit.components_.T)
