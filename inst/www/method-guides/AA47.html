Quantile Regression

Statistical method reference guide

Overview and appropriate use

Purpose

Quantile regression estimates how predictors relate to a specified conditional quantile of an outcome rather than only its conditional mean.

Example research questions

Is an exposure more strongly associated with very high blood pressure than median blood pressure?

Design requirements

Outcome with meaningful ordering, suitable predictors, and enough observations around the chosen quantiles.

Strengths

Reveals heterogeneous relationships across the outcome distribution and can be less dominated by extreme values for median regression.

Limitations

Sparse tail quantiles can be unstable; coefficient differences across quantiles are not automatically individual-level effects.

When not to use it

Do not interpret a conditional quantile slope as a change for a particular person without additional assumptions.

Illustrative research scenario (hypothetical)

Estimate associations of age with median and 90th-percentile hospital costs.

Mathematical foundation

Mathematical foundation

conditional quantile optimization

\(\hat{\boldsymbol{\beta}}_\tau=\arg\min_{\boldsymbol{\beta}}\sum_i\rho_\tau(y_i-\boldsymbol{x}_i^\top\boldsymbol{\beta}),\quad \rho_\tau(u)=u(\tau-\mathbf{1}[u<0])\)
View LaTeX source
\hat{\boldsymbol{\beta}}_\tau=\arg\min_{\boldsymbol{\beta}}\sum_i\rho_\tau(y_i-\boldsymbol{x}_i^\top\boldsymbol{\beta}),\quad \rho_\tau(u)=u(\tau-\mathbf{1}[u<0])

Symbols

τ: chosen quantile (0<τ<1); ρ_τ: asymmetric check loss; β_τ: quantile coefficients.

Explanation

Estimates conditional outcome quantiles rather than the conditional mean.

Important scope limitation

Different quantiles may have different covariate effects; standard OLS inference does not apply unchanged.

Assumptions and diagnostics

Assumptions and conditions

Quantile level is prespecified; conditional quantile function has an appropriate predictor form and inference reflects dependence/heteroskedasticity.

Diagnostics to perform

Plot fitted quantiles against data, compare slopes across quantiles, check sparse tails and influence, and use appropriate bootstrap/resampling units.

Consequences of violations

Misspecified conditional quantile relations or naive standard errors can bias interpretation, especially in tails or clustered data.

Diagnostic caveats

Quantile regression does not require normally distributed errors, but its coefficient interpretation differs from mean regression.

Understanding the results

Primary outputs

Conditional quantile-regression coefficients for prespecified quantile τ and predicted conditional quantiles.

Inference and tests

Use suitable rank, asymptotic or bootstrap intervals/tests accounting for the sample design.

Effect sizes and intervals

Report quantile-specific slope or predicted quantile difference with confidence interval and units.

Model fit and performance

Check quantile crossing, residual patterns and out-of-sample pinball loss; R² from least squares is not the primary fit measure.

Interpreting results

At τ = 0.90, a slope of 2 estimates a two-unit difference in the conditional 90th percentile per X unit.

Common mistakes

A conditional quantile slope does not necessarily describe changes for individuals who stay at the same percentile.

Example report wording (placeholder values)

At τ = [tau], quantile slope for [X] = [estimate] [units] (95% CI [limits]).

R tutorial

Learning goal

Estimate conditional median shifts instead of mean shifts.

Simulated data

160 independent observations with a continuous outcome, continuous covariate, and two groups.

Packages

quantreg

R example

set.seed(2026)
n <- 160
x <- rnorm(n)
group <- factor(rep(c("Control", "Treatment"), each = n/2))
y <- 10 + 1.3 * (group == "Treatment") + 0.9 * x + rnorm(n, sd = 2)
d <- data.frame(y, x, group)

fit<-quantreg::rq(y~x+group,tau=.5,data=d)
print(summary(fit,se="nid"))

Output to inspect

Median regression coefficients at tau=0.5.

Limitations and checks

Conditional quantile coefficients are not changes in unconditional population medians.

Simulated data

Packages

numpy, pandas, statsmodels

Python example

import numpy as np
import pandas as pd
rng = np.random.default_rng(2026)
n = 160
x = rng.normal(size=n)
group = np.repeat(["Control", "Treatment"], n // 2)
y = 10 + 1.3 * (group == "Treatment") + 0.9 * x + rng.normal(scale=2, size=n)
d = pd.DataFrame({"y": y, "x": x, "group": group})

import statsmodels.formula.api as smf
fit=smf.quantreg("y ~ x + C(group)",data=d).fit(q=.5)
print(fit.summary())
